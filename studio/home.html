튜토리얼 - 처음 만드는 슬라이드

    
다섯 단계로 작성 흐름을 익힙니다. 직접 따라 해 보려면 데모를 열어 같은 화면에서 해 보세요.

    

      
1
작업 공간을 정한다

        제작 도구(nexa-slide 엔진)는 내용을 자기 폴더에 두지 않습니다. 제작마다 작업 공간 폴더를 하나 만듭니다.
        
  • 기본 위치: 문서 폴더 아래 NexaSlide/<제목>
    • 
          
  • 고른 폴더는 저장소 관리 기준 폴더(루트)입니다: 기초 자료를 모아 정리하고 필요하면 관련 소스도 개발합니다(구조 자유). 슬라이드는 그 자료를 근거로 slides/ 에서 만듭니다. 루트에는 폴더를 만들지 않고 SLIDES.md(개념·서버 실행)와, 없을 때만 CLAUDE.md·AGENTS.md 를 둡니다.
    • 
          
  • 이미 있는 저장소에 붙이려면 "폴더·저장소 지정"으로 그 저장소를 고르고 하위 폴더는 비웁니다. 내용이 그 저장소의 git 이력으로 관리됩니다.
    • 
          
  • 작업 공간(slides/) 구성: nexa-slide.json(포트·템플릿 선택) · nexa.py(실행기 - python3 slides/nexa.py start) · content/(내용 원본) · decks/(편집 대상) · assets/(그림) · BRIEF.md(작성 방향)

      
2
템플릿을 고르고 방향을 적는다

        색·글꼴·글자 크기는 엔진의 템플릿에 있고, 작업 공간은 이름만 고릅니다. 목적·대상·작성 방향·참고 자료를 적어 두면 Claude 세션이 초안을 쓸 때 기준으로 씁니다.
        
  • 자료에 없는 내용은 지어내지 않고 확인 질문으로 남깁니다.

      
3
Studio 에서 고친다

        
  • 편집 모드: 글자를 바로 고치고, 서식 줄로 굵게·색·크기를 바꿉니다. 저장은 자동입니다.
    • 
          
  • 선택 모드: 요소를 눌러 그 자리에 요청 메모를 남깁니다. 그리기 모드: 영역을 그려 요청합니다.
    • 
          
  • 아래 검사 탭: 겹침·넘침·최소 글자 크기·슬라이드 밖을 알려 줍니다.

      
4
Claude 세션에 요청한다

        작업 공간 폴더에서 Claude Code 세션을 열고 요청 감시를 겁니다(작업 공간의 CLAUDE.md 에 명령이 있습니다).
        
  • python3 nexa.py watch_requests --stream --takeover 를 Monitor 로 실행
    • 
          
  • 머리줄 칩이 "세션 연결됨"이 되면, 남긴 메모를 "요청 N개 보내기"로 보냅니다. 처리 결과와 답변은 요청 탭에 돌아옵니다.

      
5
발표하고 내보낸다

        
  • F5 처음부터 발표 · Shift+F5 현재 슬라이드부터 · 발표 중 N 노트
    • 
          
  • "내보내기"로 편집 가능한 PPTX 를 만듭니다(Windows 에 PowerPoint 가 있으면 렌더 미리보기도).
    • 
          
  • 잘못 고쳤으면 "기록"에서 저장 시점으로 되돌립니다(자동 백업 50개).

기준 폴더 설정

  

    
새로 만들 때 기본 위치입니다. 비우면 운영체제의 문서 폴더 아래 NexaSlide 를 씁니다.

    
    

    

    
    
켜면 여러 작업 공간을 포트 하나(이 페이지의 포트)로 함께 씁니다. 작업 공간 서버는 뒤에서 따로 돌고(설정 포트가 쓰는 중이면 빈 포트로), 이 서버가 요청을 넘깁니다.
      끄면 예전처럼 그 작업 공간 서버의 포트로 바로 이동합니다. nexa.py start 로 직접 띄우는 방식은 둘 다 그대로입니다.

    

      AI 세션 전역 기본 관리자
      
작업 공간 설정(nexa-slide.local.json·nexa-slide.json)과 세션 시작 창의 선택이 이 값보다 우선합니다. 비우면 기본(claude · opus).

      
      

        

        

      

      
      
      

        

        

        

        

        

      

      
      
켜면 그 세션이 외부 웹을 검색·열람합니다. 슬라이드·요청 내용이 검색어·요청 URL 로 외부에 전달될 수 있습니다. 턴 로그에 요청한 URL 이 남습니다.

      
      
      
      
세션 시작 창에서 세션마다 켭니다. git 기록은 이 PC 의 git 사용자로 커밋하고, push 는 이 PC 의 자격 증명으로 원격에 보냅니다. 강제 push·reset --hard·clean·rebase·config·remote·git -C 는 켜도 막혀 있습니다. 작업 공간 설정에 false 를 두면 그 작업 공간에서는 꺼집니다.
