튜토리얼 - 처음 만드는 슬라이드

    
다섯 단계로 작성 흐름을 익힙니다. 직접 따라 해 보려면 데모를 열어 같은 화면에서 해 보세요.

    

      
1
작업 공간을 정한다

        제작 도구(nexa-slide 엔진)는 내용을 자기 폴더에 두지 않습니다. 제작마다 작업 공간 폴더를 하나 만듭니다.
        
  • 기본 위치: 문서 폴더 아래 NexaSlide/<제목>
    • 
          
  • 교재·프로젝트 저장소 안에 두려면 "폴더·저장소 지정"으로 그 저장소를 고르고 하위 폴더(예: slides)를 적습니다. 그러면 내용이 그 저장소의 git 이력으로 관리됩니다.
    • 
          
  • 작업 공간 구성: nexa-slide.json(포트·템플릿 선택) · nexa.py(실행기) · content/(내용 원본) · decks/(편집 대상) · assets/(그림) · BRIEF.md(작성 방향)

      
2
템플릿을 고르고 방향을 적는다

        색·글꼴·글자 크기는 엔진의 템플릿에 있고, 작업 공간은 이름만 고릅니다. 목적·대상·작성 방향·참고 자료를 적어 두면 Claude 세션이 초안을 쓸 때 기준으로 씁니다.
        
  • 자료에 없는 내용은 지어내지 않고 확인 질문으로 남깁니다.

      
3
Studio 에서 고친다

        
  • 편집 모드: 글자를 바로 고치고, 서식 줄로 굵게·색·크기를 바꿉니다. 저장은 자동입니다.
    • 
          
  • 선택 모드: 요소를 눌러 그 자리에 요청 메모를 남깁니다. 그리기 모드: 영역을 그려 요청합니다.
    • 
          
  • 아래 검사 탭: 겹침·넘침·최소 글자 크기·슬라이드 밖을 알려 줍니다.

      
4
Claude 세션에 요청한다

        작업 공간 폴더에서 Claude Code 세션을 열고 요청 감시를 겁니다(작업 공간의 CLAUDE.md 에 명령이 있습니다).
        
  • python3 nexa.py watch_requests --stream --takeover 를 Monitor 로 실행
    • 
          
  • 머리줄 칩이 "세션 연결됨"이 되면, 남긴 메모를 "요청 N개 보내기"로 보냅니다. 처리 결과와 답변은 요청 탭에 돌아옵니다.

      
5
발표하고 내보낸다

        
  • F5 처음부터 발표 · Shift+F5 현재 슬라이드부터 · 발표 중 N 노트
    • 
          
  • "내보내기"로 편집 가능한 PPTX 를 만듭니다(Windows 에 PowerPoint 가 있으면 렌더 미리보기도).
    • 
          
  • 잘못 고쳤으면 "기록"에서 저장 시점으로 되돌립니다(자동 백업 50개).

    • 
          
  • 편집 · 선택 · 그리기 모드, 서식 줄, 실행 취소
