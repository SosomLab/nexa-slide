글꼴 받기·설치 안내

규칙
  • 슬라이드 글꼴은 되도록 아래 목록의 무료 글꼴(누구나 직접 받아 문서·상업용으로 쓸 수 있는 SIL OFL 등)로 고릅니다. 받는 사람도 같은 글꼴을 구할 수 있어야 같은 모양으로 보입니다.
  • 글꼴 파일은 nexa-slide 엔진에 두지 않습니다. 작업 공간 fonts/ 에 두고, 글꼴 세트는 작업 공간 nexa-slide.json 의 fontPresets 로 정합니다.
  • 목록에 없는 글꼴(회사 전용 서체 등)은 전용으로 표시합니다 — 받는 사람이 구할 수 있는지, 배포가 허용되는지 확인하고, 밖으로 보낼 때는 내보내기 → PPTX 글꼴 포함을 씁니다.

이 작업 공간에서 쓰는 글꼴

무료 글꼴 목록

공식 배포처에서 직접 받습니다. "세트"는 nexa-slide 기본 글꼴 세트에서 쓰는 글꼴입니다.

설치 방법

Windows
  1. 받은 zip 을 풀고 굵기별 .ttf·.otf 를 고른다(가변 글꼴보다 정적 파일).
  2. 파일을 오른쪽 단추 → 설치(현재 사용자) 또는 모든 사용자용으로 설치.
  3. PowerPoint·브라우저를 다시 연다.
작업 공간 fonts/ 에 넣은 글꼴은 그 폴더에서 python3 nexa.py install_fonts 로 한 번에 설치(관리자 권한 불필요).
macOS
  1. 글꼴 파일을 두 번 눌러 서체 관리자(Font Book) → 설치.
  2. 또는 ~/Library/Fonts 에 복사.
  3. PowerPoint 를 다시 연다.
맑은 고딕·Consolas 는 Windows 기본 글꼴이라 macOS 에는 없다 — 받는 쪽이 macOS 면 무료 글꼴 세트를 쓴다.
Linux
  1. ~/.local/share/fonts 에 복사.
  2. fc-cache -f
  3. 프로그램을 다시 연다.
python3 nexa.py install_fonts 도 같은 일을 한다.
설치 없이 보내기 — 편집기 내보내기 → PPTX 내보내기 — 글꼴 포함(Windows·PowerPoint 필요): 쓴 글자만 PPTX 안에 넣어 받는 사람이 설치하지 않아도 같은 모양으로 본다. 포함 금지(fsType) 글꼴은 들어가지 않는다. 쓴 글꼴은 내보낼 때마다 out/<덱>.fonts.json 에 기록된다.
