# 강의 교안 시작용 (`lecture-course`)

여러 날짜에 걸친 강의 교안을 처음부터 같은 뼈대로 쓰기 위한 시작용 내용이다.
디자인은 템플릿 `lecture` 를 그대로 쓰고, 이 시작용은 **구성·번호 체계·작성 규약**과 레이아웃별 예시를 준다.
내용은 자리 표시와 일반 예제(주문 관리: `CUSTOMERS`·`ORDERS`·`ORDER_ITEMS`·`PRODUCTS`)이며, 실제 교재 하나를 익명화해 정리한 것이다.

```
python3 <엔진>/studio/init_workspace.py <작업 공간> --title "과정 이름" --starter lecture-course
python3 <작업 공간>/nexa.py render_mermaid ch01      # 다이어그램(이미 PNG 가 들어 있어 고칠 때만)
python3 <작업 공간>/nexa.py build_deck ch00 --force
python3 <작업 공간>/nexa.py build_deck ch01 --force
python3 <작업 공간>/nexa.py start
```

## 들어 있는 것

| 파일 | 내용 |
|---|---|
| `content/_common.json` | 모든 장 덱에 붙는 공통 슬라이드 - 메인 표지 · 전체 목차(일차별 장 목록) · EoD. `course_version` 은 표지·EoD 의 `{course_version}` 자리에 들어간다 |
| `content/ch00.json` | 과정 안내 장 - 장 표지 · 장 목차(절·필수/심화·분량) · 학습 목표 · 절/소분류 · 흐름 · 시퀀스 · 표 · 카드 · 전후 비교 · 코드 발췌 · 실습 · 코드+실행계획 · 실행계획 해설 표 · 예제 파일 · 장 정리 (본문 24장) |
| `content/ch01.json` | 이론 장 예시 - 정의 표(원문 요약 + 우리 예제) · 다이어그램(Mermaid) · 설계 단계 흐름 · 실습 · 심화 절 (본문 12장) |
| `assets/ch01/` | 다이어그램 PNG 와 원본 `.mmd` |
| `starter.json` | 일차 이름(`partLabels`)·표지 배지 등 `nexa-slide.json` 에 넣을 선택값 |

장 덱 하나는 **앞부분 공통(표지·전체 목차·개정 이력) + 장 블록 + EoD(다음 장 안내)** 로 빌드된다(`common: true`).
`build_deck.py book` 은 장들을 목차 순서로 모은 통합본을 만든다.

## 번호 체계

| 대상 | 형식 | 규칙 |
|---|---|---|
| 장 | `ch00`·`ch01` … | **장 번호 = 교육 순서**. 장을 새로 넣으면 뒤 장 번호를 다시 매기고 참조를 함께 고친다 |
| 절 | `0.1`·`1.4` | 장 번호 + 순번. 교육 순서와 같게(나중에 추가한 절도 순서대로 다시 매김) |
| 소분류 | `0.2.1` | 절이 길 때만. `subsection` 슬라이드가 같은 절의 소분류를 함께 보여 준다 |
| 실습 | `실습 00-01` | 장-순번. 파일도 같은 접두(`sql/ch00/00-01_*.sql`) |
| 위치 표시(crumb) | `ch00 › 0.2 › 0.2.1` | 슬라이드 왼쪽 아래 - 각주가 있어도 같은 자리 |
| 교안 버전 | `v0.1` → `v1.0` | 내용 변경 = 소수 첫째 자리, 교육 회차 확정본 = 정수. 장마다 `revisions` |

## 장 구성 순서

1. **장 표지**(`chapter`) - 현장의 문제 상황에서 시작하는 두 줄 소개
2. **장 목차**(`chapter_toc`) - 절 목록과 필수(`req`)/심화(`adv`), `stats` 로 절·실습 수와 예상 시간
3. **학습 목표**(`bullets`) - "~한다"로 끝나는 행동 3~7개, 각 목표는 뒤의 절·실습과 연결
4. 절마다 **절 구분**(`section`, tags: `req`/`adv` · `theory`/`lab`) → 본문 슬라이드 → 실습(`lab`)
5. **예제 파일**(`files`) - 슬라이드에는 요지만, 전체는 파일로
6. **장 정리**(`summary`) - "이것만은 기억한다" 4~7줄

필수 절은 정해진 교시에, 심화 절과 선택 장은 그날 마지막 심화 세션에서 다룬다(강사가 대상에 맞춰 범위 조정).

## 근거·각주·노트

- 근거가 있는 문장 끝에만 **각주 표식** `[[theory|¹]]` 을 단다. 자료명·절·쪽은 슬라이드의 `source` 목록에 ¹ ² 순서로 적는다.
  화면에는 위치 표시 바로 위에 작은 글씨(9pt)로 `1 자료 §절, 쪽    2 …` 처럼 가로로 표시된다.
- 원문은 발표자 노트의 `── 원문 (각주 순서, 원어 그대로) ──` 아래에 같은 번호로 옮긴다. 근거 없는 문장에 각주를 달지 않는다.
- 각주를 단 내용은 원본을 **요약**한다 - 용어·의미를 바꾸지 않는다. 우리 예시·해석은 원문과 섞지 않고 "강사용 예시(원본 아님)"로 표시한다.
- 노트에는 강사가 말할 순서, 원문, 다른 장 연결(`→ ch02 §2.3`)을 적는다. 슬라이드 문구는 수강자가 바로 읽히는 표현으로.

## 예제·실습

- **공통 사례**: 과정 전체에서 반복해 쓰는 업무 장면 몇 가지를 정하고(ch00 0.3 표), 모든 장의 예제·실습을 거기서 뽑는다.
- 예제 코드는 실제 스키마의 컬럼만 쓰고, 실습 환경에서 실행해 확인한 결과를 싣는다. 수치가 예시면 "수치는 예시다"라고 적는다.
- 실습 슬라이드는 단계(`steps`) 4개 안팎 + 확인 지표(`side`).
- **변수(바인드)로 쓴 SQL**은 실습과 같게 `:변수` 로 두고(값을 리터럴로 바꾸지 않는다), 바로 뒤에 두 장을 붙인다:
  ① 변수 표(`table`: 변수 · 컬럼 · 예시 값 · 값의 뜻 + 결과 행 수·실행법) ② 값을 넣은 실행(`code_plan`: 변수 값을 주석으로 단 SQL + 실제 결과).
- 표·본문 글자에는 백틱(`)을 쓰지 않는다 - 서식이 아니라 글자로 보인다. 코드 이름은 그대로 쓰거나 `**굵게**`.

## 작성 규칙

- 문장 부호는 `-`(하이픈)를 쓴다(— 대신).
- 한 슬라이드 = 한 메시지. 제목은 결론, 부제는 근거나 읽는 법.
- 그림은 Mermaid 코드(`mermaid` 필드)로 남겨 코드로 리뷰한다 - `render_mermaid.py` 가 PNG 를 만든다.
- 빌드 후 `check_layout` 으로 겹침·넘침을 0으로 맞춘다. 칩 글자 최소 pt(`t4.font.min`)는 템플릿 `lecture` 디자인 값 그대로라 남는다 - 큰 글자가 필요하면 템플릿 `lecture-large`.

## 바꿔 쓸 곳

- `nexa-slide.json` - `title` · `brand`(자기 로고·워드마크) · `partLabels`(일차 이름) · `coverBadge`
- `content/_common.json` - 표지 제목·부제·작성 조직, 전체 목차의 장 목록, `course_version`
- `content/chNN.json` - 장 내용. 새 장은 ch01 을 복사해 시작하고 전체 목차에 추가
