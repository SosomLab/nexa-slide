# 시트(엑셀) — AI 와 함께 쓰는 표 문서

> engine-request #12 · 검토와 1단계 구현. 슬라이드 덱과 같은 방식(편집기에서 보고 고치고, 요청 → 세션이 파일을 고침 → done + reply)으로
> 엑셀 시트를 함께 만든다. 파일을 주고받지 않고, 마지막에 `.xlsx` 로 내보낸다.

## 1. 구현 가능성 — 가능하다(기존 구조를 거의 그대로 쓴다)

| 덱에 있는 것 | 시트에서 | 비고 |
|---|---|---|
| `decks/<id>.json` 저장 · 버전 · `PUT ?base=` 409 충돌 | **그대로** | 시트 문서도 `decks/<id>.json` 에 `"kind":"sheet"` 로 둔다 |
| 백업·변경 원장(`.history/<id>/`) | 그대로(1단계는 덱 수준 변경 한 줄) | 셀 단위 diff 는 2단계 |
| 요청 파일 `decks/<id>.requests.json`·상태 기계·감시·하트비트 | **그대로** | 대상: `slide`=시트 탭 id, 새 필드 `range`(예 `B2:D5`) |
| 세션 저장 `draft_deck` → `save_deck --request` | 그대로 | 세션은 JSON 의 `sheets[].cells` 를 고친다 |
| 2초 폴링(`/api/version/<id>`) 다시 읽기·충돌 배너 | 같은 방식 | 시트 화면(`sheet.js`)이 따로 구현 |
| 렌더(`render.js`)·PPTX(`export_pptx.py`) | **쓰지 않는다** | 시트 화면은 격자, 내보내기는 `export_xlsx.py`(XlsxWriter) |

XlsxWriter 는 python-pptx 의 의존성이라 이미 설치돼 있고, xlsx 읽기(첨부)는 `import_doc.read_xlsx` 가 표준 라이브러리로 한다.
M365(OneDrive·Graph API) 직접 연동은 하지 않는다 — 원래 불편(파일을 열어 고치고 다시 보내기)을 없애는 것이 목적이라
**편집 원본은 nexa-slide 안의 JSON**, 엑셀은 산출물(내보내기)이다. 엑셀에서 고친 파일을 다시 들여오는 것은 2단계(가져오기).

## 2. 문서 형식

```jsonc
{
  "id": "d1a2b3c4", "title": "분기 매출", "kind": "sheet", "version": "0.1", "updated": "…",
  "slides": [],                      // 덱 도구와 호환(항상 빈 목록)
  "sheets": [{
    "id": "t01", "name": "Sheet1",
    "size": {"rows": 50, "cols": 12},  // 화면에 보이는 격자 크기(선택, 데이터보다 작으면 데이터에 맞춘다)
    "cols": {"A": 140, "C": 90},       // 열 너비 px(없으면 96)
    "rows": {"1": 30},                 // 행 높이 px(없으면 24)
    "freeze": "A2",                    // 틀 고정 - 이 셀의 위·왼쪽이 고정(선택)
    "merges": ["A1:D1"],
    "cells": {
      "A1": {"v": "분기 매출", "b": true, "size": 14, "fill": "#1F4E79", "color": "#FFFFFF", "align": "center"},
      "A2": "지역", "B2": "1분기",       // 값만 있으면 문자열·숫자·불 그대로
      "B3": 1200,
      "C3": {"v": 0.15, "fmt": "0.0%"},
      "D3": {"f": "=B3*(1+C3)", "v": 1380, "fmt": "#,##0"}
    }
  }]
}
```

셀 키 — `v` 값(문자열·숫자·불), `f` 수식(`=` 로 시작, `v` 는 마지막 계산값 캐시), `fmt` 엑셀 표시 형식, `b`·`i`·`u` 굵게·기울임·밑줄,
`color` 글자색, `fill` 배경, `align` `left|center|right`, `valign` `top|middle|bottom`, `size` 글자 크기(pt), `wrap` 줄바꿈, `note` 메모.
값이 문자열이어도 `=` 로 시작하면 수식이 아니다 — 수식은 `f` 에만 둔다.

**동적 배열(넘침)** — `FILTER`·`SORT`·`SORTBY`·`UNIQUE`·`SEQUENCE`·`TRANSPOSE` 를 쓴 수식(또는 엑셀에서 가져온 동적 배열 `"da": true`)은 결과가 여러 칸이면
오른쪽·아래 칸으로 넘친다. 넘친 칸은 계산기가 `{"v": 값, "sp": "기준 칸"}` 으로 채우고(사람·AI 는 쓰지 않는다), 자리에 값이 있으면 기준 칸이 `#SPILL!`,
결과가 없으면 `#CALC!` 이다. 결과가 줄면 남은 넘친 칸은 비운다. 다른 곳에 복사된 `sp` 칸은 값만 남는다.
내보낼 때 기준 칸은 엑셀 동적 배열 수식(`write_dynamic_array_formula`)으로 쓰고, 가져올 때 `cm`·여러 칸 배열 수식을 `da` 와 `sp` 로 되살린다.
넘친 범위 전체는 `H2#` 로 참조한다(`=SUM(H2#)` · `=H2#*10` 도 넘친다 · 넘치지 않는 칸이면 `#REF!`). 엑셀 파일에는 `ANCHORARRAY(H2)` 로 저장된다.
새 함수(LET·XMATCH·TEXTJOIN·FILTER …)는 내보낼 때 `_xlfn.`·LET 이름은 `_xlpm.` 을 붙이고(엑셀이 `#NAME?` 없이 연다 - Excel 로 확인), 가져올 때 뗀다.

**표(엑셀 표)** — 탭 `tables: [{"name": "매출표", "ref": "A1:D5", "cols": ["지역", "1분기", …], "header": true, "totals": false, "style": "TableStyleMedium2"}]`.
수식에서 구조적 참조로 쓴다 - `매출표[1분기]`(데이터 행) · `매출표[[#Headers],[2분기]]` · `매출표[#All]` · `매출표[[1분기]:[2분기]]` · 표 안에서 `[@1분기]`(이 행).
가져올 때 `xl/tables` 를 읽고(파일 형식 `[#This Row],` → `@`), 내보낼 때 `add_table` 과 파일 형식으로 되돌린다(Excel 로 확인).
표 정의 없이 가져온 옛 문서의 구조적 참조·외부 통합 문서 참조처럼 계산기가 읽지 못하는 수식은 엑셀이 마지막에 계산한 값을 그대로 둔다.

**이름 정의(엑셀 이름 관리자)** — 문서 `names`(통합 문서 범위)와 탭 `names`(그 시트 범위) = `{"이름": "값"}`.
값은 범위(`"데이터!$B$2:$B$5"` - 문서 이름은 탭 이름을 붙인다, 탭 이름은 붙이지 않으면 그 탭) · 상수(`"0.1"`) · 수식(`"=…"`).
수식에서 이름 그대로 쓴다 - `=SUM(매출)*세율`. 같은 이름이면 탭 이름이 문서 이름보다 먼저다. 정의가 없는 이름을 쓴 셀은 엑셀이 마지막에 계산한 값을 그대로 둔다(가져온 문서가 `#NAME?` 로 덮이지 않게).
행·열을 넣거나 지우면 이름 정의도 옮긴다 - 범위 안에 넣으면 범위가 늘고, 지운 칸만 가리키던 이름은 `#REF!`(`sheet_struct.py`·화면 `shiftAxis`, 동시 편집 병합도 같다 - [collab.md](collab.md) 3-2).
가져오기·내보내기는 엑셀 `definedNames` 와 주고받는다.

**수식형 요약 `GROUPBY`·`PIVOTBY`**(엑셀 365, 넘친다) — 피벗 표 대신 수식 한 칸으로 요약한다.
`=GROUPBY(행 필드, 값, 집계)` 은 행 필드별 집계 + 맨 아래 `Total`, `=PIVOTBY(행 필드, 열 필드, 값, 집계)` 은 행×열 표 + 행·열 합계.
집계는 함수 이름(`SUM`·`AVERAGE`·`COUNT`·`COUNTA`·`MAX`·`MIN`·`MEDIAN`·`PRODUCT`)이나 LAMBDA(`LAMBDA(v,SUM(v)/2)`)·이름 정의 함수.
GROUPBY 는 행 필드·값 여러 열, 머리글(0·1·2·3 - 생략하면 자동, 2 는 머리글 없는 자료에 `Row Field 1`·`Column Field 1`·`Value 1` 을 만들어 붙인다), 합계(1 아래·-1 위·0 없음 · 2 이상이면 깊이별 소계가 들어가고 맨 합계 이름이 `Grand Total`), 정렬, 거르기 배열을 받는다.
PIVOTBY 는 행 필드·열 필드·값 모두 여러 열을 받는다. 정렬(두 함수 공통)은 `±n`(키 열 수보다 큰 번호면 값 열로 정렬)이고 `{-1,2}` 처럼 배열이면 단계별로 정렬한다(엑셀에 맞춘 규칙 요약은 CHANGELOG 0.24.10).
배열 상수 `{1,-3;"가",TRUE}`(`,` 열 · `;` 행)도 수식 어디에나 쓸 수 있다. 엑셀 파일에는 `_xlfn.GROUPBY(…,_xleta.SUM)` 으로 쓰고 가져올 때 뗀다.

**LAMBDA 계열**(엑셀 365) — `LAMBDA(매개변수…, 식)` 와 그것을 받는 `MAP`·`BYROW`·`BYCOL`·`REDUCE`·`SCAN`·`MAKEARRAY`.
`=SUM(MAP(B2:B5,LAMBDA(x,x*2)))` · `=BYROW(B2:C5,LAMBDA(r,SUM(r)))`(행마다 하나 - 넘친다) · `=REDUCE(0,B2:B5,LAMBDA(a,v,a+v))` · `=SCAN(0,B2:B5,LAMBDA(a,v,a+v))`(누계) · `=MAKEARRAY(3,2,LAMBDA(r,c,r*c))`.
LET 이름에 담아 `=LET(f,LAMBDA(a,b,a+b),f(2,3))` 으로 부르고, **이름 정의에 담으면 사용자 함수**다 - 이름 관리자 `세후 = LAMBDA(x,x*0.9)` → 셀에서 `=세후(1000)`
(자기를 부르는 재귀는 깊이 200까지). 칸 값이 함수로 남으면 `#CALC!`, 인수 개수가 틀리면 `#VALUE!`. 엑셀 파일은 매개변수에 `_xlpm.`, 이름 정의 안의 LAMBDA·새 함수에 `_xlfn.` 을 붙인다(가져올 때 뗀다).

**링크 `HYPERLINK(주소, [보일 글])`** — 칸에는 보일 글(없으면 주소)이 나오고, **Ctrl(맥 ⌘)+클릭**으로 이동한다. 그냥 클릭은 칸 선택 그대로이며, 링크 칸에 마우스를 올리면 "Ctrl+클릭 = 링크로 이동"이 보인다.
- 문서 안 이동: `"#탭!A1"`·`"#'탭 이름'!A1:B2"` = 그 탭으로 옮겨 칸·범위를 선택 · `"#A1"` = 이 탭 · `"#이름"` = 이름 정의(탭 범위 이름을 먼저, 없으면 문서 이름).
- 바깥 주소: `https://`·`http://`·`mailto:`·`ftp://`·`www.` 은 새 탭으로 연다(`www.` 은 `https://` 를 붙여서). 그 밖의 주소나 찾을 수 없는 대상은 이동하지 않고 알림만 띄운다.
- 계산 값은 엑셀과 같이 보일 글이다(`sheet_calc.py` 와 같음). 화면은 `NexaCalc.link(문서, 탭, 칸)` 으로 이동할 곳을 구한다.

**자동 필터(엑셀 자동 필터, Ctrl+Shift+L)** — 문서에 저장되어 사람·AI·엑셀 파일이 같은 필터를 본다. 탭 `filter`:
```json
"filter": {"ref": "A1:D20", "cols": {"B": {"vals": ["서울", ""]}, "C": {"cond": [{"op": "gt", "v": 100}, {"op": "lt", "v": 500}], "or": false}}, "rows": ["5", "9"]}
```
- `ref` = 필터 범위(첫 행이 머리글) · `cols` = 열 문자마다 조건 · `rows` = 지금 가린 행 번호.
- 조건 한 열에 하나:
  - 값 고르기 `{"vals": [보일 글…]}` - `""` 는 빈 칸.
  - 사용자 지정 `{"cond": [{op, v}, {op, v}], "or": true|false}` - op = `eq`·`ne`·`gt`·`ge`·`lt`·`le`·`begins`·`ends`·`contains`·`notContains`, `eq`·`ne` 는 `*`·`?` 와일드카드.
  - 상위 10 `{"top": n}` - 하위면 `"bottom": true`, 개수 대신 % 면 `"pct": true` 를 더한다.
  - 색 `{"fill": "#RRGGBB"}`·`{"font": "#RRGGBB"}` - `""` 는 색 없음.
- **가린 행은 엑셀처럼 조건을 바꾸거나 [다시 적용] 할 때만 다시 계산한다** - 값을 고쳐도 행이 바로 사라지지 않는다. 다시 적용하면 범위 바로 아래에 붙여 넣은 줄까지 범위를 넓힌다.
- 화면: 머리글 ▼ 메뉴 = 정렬·색 기준 정렬·열 필터 해제·색 기준 필터·텍스트/숫자 필터(사용자 지정 두 조건·상위 10)·검색(＋ "현재 선택 영역을 필터에 추가"). 조건이 걸린 데이터 행 번호는 파랑. 데이터 ▾ = 필터 켜기/끄기·지우기·다시 적용.
- 행·열 삽입·삭제를 따라간다 - 범위·`rows`·`cols` 열 문자(`sheet.js` `shiftAxis` ↔ `sheet_struct.py`, 골든 `sheet_struct_cases.json`). 범위가 통째로 지워지면 필터도 없어진다.
- 동시 편집: `filter` 는 탭 속성 하나로 병합한다 - 두 창이 같은 때 다른 열의 조건을 바꾸면 한쪽만 남는다(충돌로 기록).
- xlsx: 가져오기는 `autoFilter`(값·사용자 지정·상위 10·색) → `filter`, 범위 안 숨긴 행 → `filter.rows`. 내보내기는 범위·조건·가린 행(색 조건은 XlsxWriter 가 못 써서 범위·가린 행만).

**VBA 사용자 함수(xlsm, 0.25.3)** — 표준 모듈의 `Function` 을 칸에서 `=이름(…)` 으로 부르면 브라우저의 실행기(`studio/vba.js`)가 계산한다(엑셀 없이).
- 문서 `macros.modules: [{"name": "Module1", "kind": "std", "code": "…"}…]`(kind = `std` 표준 · `doc` 문서 · `cls` 클래스) - xlsm 을 가져올 때 넣는다. 전에 가져온 문서는 서버가 vbaProject.bin 에서 읽어 준다(`GET /api/vba/<id>`).
- 되는 문법: Function·Sub · Dim·ReDim(Preserve)·Const · If·For·For Each·Do·While·Select Case · Exit · On Error Resume Next · 배열 · ByRef/ByVal · 선택 인수 · ParamArray · Range 인자(`.Value`·`.Cells`·`.Count`·`.Rows.Count`·`.Row`·`.Address`) · 내장 함수 약 70개 · `WorksheetFunction.<시트 함수>`.
- 못 쓰는 문법(With·GoTo·New·날짜 상수·시트 쓰기 등)이 든 함수는 계산하지 않고 **엑셀이 저장한 값을 그대로** 둔다. 실행 오류는 `#VALUE!`, 끝나지 않는 반복은 500만 단계에서 멈춘다. 모듈과 같은 이름의 함수·문서/클래스 모듈의 함수는 엑셀처럼 `#NAME?`.
- **보안(0.25.8)**:
  - 실행기는 코드를 해석만 한다(eval 없음). 파일·네트워크·Shell·개체 만들기는 아예 없어 이 편집기에서는 매크로가 PC 에 닿지 않는다. 서버는 VBA 를 실행하지 않는다.
  - 문서의 코드가 화면을 멈추거나 탭을 죽이지 못하게 한도(`NexaVBA.LIMIT`)를 둔다. 넘으면 그 칸은 `#VALUE!`.

    | 한도 | 값 |
    |---|---|
    | 배열 | 100만 칸 |
    | 문자열 | 1천만 자 |
    | 부르기 깊이 | 500 |
    | 반복 | 500만 단계 |
    | 한 번 부르기 | 2초 |

  - `Like` 는 정규식 없이 비교한다(되짚기 폭주 없음, 잘못된 패턴은 오류 93). 형식 이름을 조회할 때는 그 표에 실제로 정의된 이름만 본다(`constructor` 같은 JS 기본 속성이 값으로 새지 않게).
  - 화면에서는 계산을 **Worker**(`studio/vbaworker.js`, `NexaVBA.client`)에서 한다. 처음 보는 부르기(함수 + 인자)는 그 칸과 그 칸에 기대는 칸의 저장값을 그대로 두고 Worker 에 맡긴다. 결과가 오면 다시 계산한다(결과는 함수 + 인자별로 기억).
  - Worker 가 4.5초 넘게 답이 없으면 화면이 Worker 를 끝내고, 그 부르기를 오류로 둔 뒤 새 Worker 로 이어 간다. node(시험·`xlsm_calc.js`)는 예전처럼 바로 계산한다.
- **엑셀에서 위험할 수 있는 매크로(0.25.8)**:
  - `NexaVBA.risks(modules)` 가 줄마다 다음을 찾는다. Python `vba_project.risks` 는 vba.js 의 `RISKS` 를 그대로 읽어 같은 규칙을 쓴다.
    - 자동 실행: `Auto_Open`, `Workbook_*`·`Worksheet_*` 이벤트
    - 프로그램 실행: `Shell`, `CreateObject`·`GetObject`, `Declare`(DLL), `Application.Run`·`Evaluate`, `SendKeys`
    - 파일·코드·레지스트리: 파일 쓰기·지우기·`SaveAs`, `VBProject`(코드 고치기), 레지스트리
    - 네트워크·명령: 네트워크(`URLDownloadToFile`·`XMLHTTP`·URL), 명령·실행 파일(`WScript`·`PowerShell`·`cmd`·`.exe` 등)
  - 주석은 빼고 본다.
  - 가져오기 경고, 코드 창(⛨ 줄·모듈 목록 개수), 내보내기 기록에 알린다.
  - 내보낼 때 위험 줄이 있으면 **확인창**에서 [매크로 포함 .xlsm] / [매크로 빼고 내보내기 .xlsx] / [취소] 를 고른다(`POST /api/export/<id>?macros=0`, `export_xlsx.py --no-macros`).
  - 문서·클래스 모듈(ThisWorkbook 등)도 지금처럼 고칠 수 있고, 위험 표시만 한다.
- **{ } VBA 코드 창**(매크로가 있는 문서): 모듈 목록·코드 편집(Ctrl+S = 적용)·표준 모듈 더하기·지우기·못 쓰는 문법 경고·칸에서 부를 수 있는 함수 목록. [적용·다시 계산] 이 `macros.modules` 에 저장하고 그 함수를 쓰는 칸을 다시 계산한다.
- 내보내기: vbaProject.bin 을 **늘** 모듈 소스로 다시 쓴다(0.25.8 - 전에는 고쳤을 때만). `vba_project.py` 가 컴파일된 코드(p-code·`__SRP_`)를 버리고 판을 0xFFFF 로 둬, 엑셀이 열 때 소스에서 다시 컴파일한다.
  - 원본에 남은 p-code 가 화면에 보이는 소스와 다른 코드를 돌리지 못하게 하려는 것이다(VBA stomping).
  - 다시 쓰지 못하는 프로젝트는 원본을 넣지 않고 매크로를 빼고 .xlsx 로 내보낸다.
- 동시 편집: `macros` 는 문서 최상위 키 하나로 병합한다(두 창이 같은 때 모듈을 고치면 한쪽만 남는다).

**그림 편집(0.25.4)** — 탭 `drawings`(아래 5절)의 그림을 화면에서 다룬다.
- 누르면 고르고 Ctrl·Shift 로 여럿 - 고른 그림이 **요청 대상**이 된다(요청에 `element`·`elements` = 그림 id, [claude-session.md](claude-session.md)).
- 그림 id = `drawings[].id`, 없으면 `src` 파일 이름에서 확장자를 뺀 것, 그것도 없으면 `img<순번>`(1부터).
- 끌어 옮기기(놓은 칸 + 남는 px → `at`·`dx`·`dy`) · 모서리 손잡이로 크기(Shift = 비율 그대로) · Delete 로 지우기.
- 넣기: 붙여넣기 · 끌어 놓기 · 오른쪽 클릭 "그림 넣기…" - 작업 공간 그림 폴더에 올려 지금 칸에 고정한다.

**편집 기능(엑셀처럼, 0.25.4)**
- 단축키: Ctrl+End · Ctrl/Shift(+Ctrl)+Space(열·행·모두) · Ctrl+;(오늘) · Ctrl+PageUp/Down(탭) · Ctrl+5(취소선) · Ctrl+9/0(행·열 숨기기) · Ctrl+-/+(행·열 지우기·넣기) · Ctrl+K(HYPERLINK) · Ctrl+1(셀 서식) · Shift+F2(메모) · Ctrl+Shift+%·!·$. Ctrl+숫자는 브라우저가 가져갈 수 있어 같은 일을 메뉴·단추로도 한다.
- **수식 참조 표시(0.25.16, 엑셀과 같다)**: 수식을 고치는 동안(셀 편집 칸·수식 줄) 참조마다 색을 정해 격자의 그 범위에 색 테두리(모서리 점)를, 수식 글자에는 같은 색을 입힌다. 같은 참조는 같은 색이고, `'탭'!A1` 은 그 탭일 때만 테두리, 글 상수("A1") 안은 참조가 아니다. 열·행 전체(`A:B`·`3:5`)도 된다.
- **고른 조각 계산(F9)**: 수식 안의 일부(예: `SUM(A13:A16)`)를 고르면 아래에 `= 값` 을 미리 보이고, **F9** 를 누르면 그 조각을 값으로 바꾼다(Ctrl+Z 로 되돌림, Esc 는 편집 전체 취소). 고르지 않고 F9 면 수식 전체 값을 알린다. 완전한 식이 아닌 조각은 미리 보기 없음. 계산은 `NexaCalc.evalText`(문서는 바꾸지 않는다).
- **넘침(0.25.17, 엑셀과 같다)**: 줄바꿈 없는 글(숫자·오류 아님, 수식 결과 글 포함)이 칸보다 길면 빈 옆 칸으로 이어 보인다. 왼쪽 정렬은 오른쪽, 오른쪽 정렬은 왼쪽, 가운데는 양쪽으로. 값·수식이 있는 칸·병합·숨긴 열·틀 고정 칸에서 멈추고, 이어진 칸 사이 눈금선은 감춘다(직접 준 테두리는 그대로). 화면 표시만 - 문서·내보내기는 그대로.
- **셀 서식 창**(Ctrl+1): 표시 형식·맞춤·줄바꿈·글꼴 꾸밈·크기·색·채우기 - 바꾼 속성만 고른 범위 모두에.
- 표시 형식 단추(% · 쉼표 · 자릿수 늘림·줄임) · **서식 복사 붓**(한 번 누르면 한 번, 두 번이면 Esc 까지 - 값·수식·메모는 그대로) · 머리 경계 두 번 누르기 = 열 너비·행 높이 자동 맞춤 · **메모**(Shift+F2, 칸 오른쪽 위 빨간 삼각형).
- 데이터 ▾: 중복된 항목 제거(모든 열이 같은 행 - 처음 것만) · 텍스트 나누기(쉼표·탭·공백·직접).
- 확대·축소: 아래 막대 · Ctrl+휠(문서마다 기억).
- 셀 `strike: true` = 취소선(가져오기·내보내기도).

**오른쪽 패널(0.25.6)** — 편집기처럼 **속성 · 요청 · 기록 · 변경** 네 탭(`studio/sheetside.js`).
- 속성: 고른 셀·범위(값·수식·표시 형식·글꼴·색·채우기·맞춤·줄바꿈·메모·열 너비·행 높이·탭 눈금선) 또는 고른 그림(이름 id·고정 칸·위치·크기(비율 고정)·대체 텍스트·순서·원래 크기·복제·지우기)을 바로 고친다.
- 그림 오른쪽 클릭: 슬라이드 요소 메뉴처럼 복제·지우기·순서 4가지·원래 크기·이름·대체 텍스트·속성·요청 메모·새 탭에서 열기.
- 기록: 저장 전 자동 백업 - 되돌리기(원장 `restore`, Ctrl+Z 가능). 변경: 원장([change-ledger.md](change-ledger.md)) - 탭 = 장, 셀·그림 = 요소. 확인하지 않은 변경은 격자에 파란 점선.

**엑셀 ↔ 시트 복사·붙여넣기(0.25.5)** — 복사하면 글(탭 구분)과 함께 HTML 표를 클립보드에 넣는다(굵게·기울임·밑줄·취소선·글자색·채우기·맞춤·크기·줄바꿈·병합, 숫자는 `x:num`).
- 엑셀·웹에서 복사한 HTML 표를 붙이면 값은 입력처럼(숫자·날짜 알아봄) 넣고, 서식은 인라인 style 과 `<style>` 의 `.xlNN` 규칙에서 읽어 칸에, `rowspan`·`colspan` 은 병합으로 넣는다.
- 이 화면에서 복사한 것은 HTML 대신 원래 수식·서식 그대로 붙인다(내부 클립). 그림만 있으면 그림으로 넣는다.

**글꼴 크기 기준 `font`** — 문서 `font: {"name": "맑은 고딕", "size": 11, "mdw": 8, "rowPx": 22}`.
엑셀은 표준 글꼴의 숫자 폭(`mdw`, px)으로 열 너비를 px 로 바꾸고, 높이를 정하지 않은 행은 글꼴로 정한다(`rowPx`). 가져올 때 실제 글꼴(테마 한글 글꼴까지)로 재서 남기고(Calibri 11 의 7·20 이면 생략), 내보낼 때 같은 값을 써서 열 너비·그림 크기가 엑셀과 맞는다.

**교차 검증** — `python3 studio/tests/xlsm_crosscheck.py <원본.xlsm> [--keep 폴더] [--max 20] [--no-excel]`:
가져오기 → 계산(Python·JS 계산기 = 엑셀 저장값) → 내보내기 → 다시 가져오기(문서 전체가 같은가) → VBA 모듈 소스 비교. Windows + 엑셀이 있으면 원본·저장본을 엑셀로 다시 계산해 수식·값·숨긴 행열·필터·이름·그림·단추까지 견준다(없거나 `--no-excel` 이면 그 단계만 건너뛴다). 원본 파일은 읽기만 한다.

## 3. 요청(세션 규약)

편집기 요청 항목 `{deck, id, slide, range, text, …}` — `slide` 는 시트 탭 id, `range` 는 고른 셀 범위(`A1`, `B2:D5`).
세션은 `kind:"sheet"` 문서면 `sheets[]` 의 `cells` 를 고친다(수식은 `f`, 값은 `v`, 계산값 `v` 는 비워 두면 화면이 다시 계산).
나머지 순서(`working` → `draft_deck` 사본 → Edit → `save_deck --request` → `done` + `reply`)는 슬라이드와 같다.

## 4. API

| | |
|---|---|
| `POST /api/decks {action:"create", kind:"sheet", title}` | 새 시트 문서(탭 1개). `GET /api/decks` 항목에 `kind` |

## 5. 시트 테마 — 슬라이드 템플릿처럼

회사 산출물 엑셀은 모양이 정해져 있다. 표지(로고·과제명·문서명·날짜), 개정 이력, 개요(문서 정보·범례), 요약, 상세 목록이 들어가고, 머리 색·테두리·글꼴·바닥 로고가 같다.
테마는 이것을 **색·글꼴(palette) + 이름 있는 셀 스타일(styles) + 페이지 틀(pages) + 로고(그림)** 로 묶는다. 슬라이드 템플릿이 장 레이아웃과 색을 묶는 것과 같은 방식이다.

| 위치 | 내용 |
|---|---|
| 엔진 `studio/sheet_themes/<이름>/theme.json` | 공개 테마만 둔다(로고 없음, 작업 공간 brand 로고 `@brand/logo` 를 쓴다). `basic`(기본 산출물: 표지·이력·개요·요약·상세목록) · `screen-spec`(화면 설계서 0.25.13: 개요·변경이력·사용테이블목록·테이블정의·화면_Tab1·화면레이아웃(셀로 그린 와이어프레임)·코드소스·쿼리·동작·유효성검증 - 실제 설계서의 구조·서식만, 내용은 일반 예시. 고칠 때는 `build.py` 를 고쳐 다시 만든다) |
| 작업 공간 `assets/sheet-themes/<이름>/theme.json` + 그림 | 회사 테마. 로고 같은 상표 파일은 엔진 저장소에 넣지 않는다 |

```jsonc
{
  "name": "corp", "label": "회사 산출물", "font": "맑은 고딕", "size": 10, "grid": false,
  "palette": {"primary": "#2C3E50", "secondary": "#44607A", "line": "#BFC9D4", "band": "#EDF1F5", "input": "#FFF2CC", "warn": "#C0392B", "muted": "#7F8C8D"},
  "styles": {                                  // 셀 키(b·color·fill·align·valign·size·wrap·fmt·bd)의 묶음. 색은 팔레트 이름이나 #RRGGBB
    "title":   {"size": 16, "b": true, "color": "primary"},
    "section": {"size": 12, "b": true, "color": "primary"},
    "header":  {"b": true, "color": "#FFFFFF", "fill": "primary", "align": "center", "valign": "middle", "wrap": true, "bd": "line"},
    "label":   {"b": true, "color": "#FFFFFF", "fill": "secondary", "align": "center", "bd": "line"},
    "cell":    {"bd": "line", "valign": "middle"},
    "key":     {"b": true, "color": "primary", "align": "center", "bd": "line"},
    "input":   {"fill": "input", "align": "center", "bd": "line"},
    "warn":    {"b": true, "color": "warn"}
  },
  "vars": {"client": "", "project": "", "author": "", "version": "1.0"},   // 페이지 글의 {{이름}} 자리(새 시트를 만들 때 채운다, 그 밖에 {{title}}·{{date}})
  "pages": [                                   // 시트 탭 틀 - 형식은 2절 탭과 같고 셀에 "s": "<스타일>" 과 {{자리}} 를 쓴다
    {"kind": "cover",    "name": "표지", ...}, {"kind": "history", "name": "이력", ...},
    {"kind": "overview", "name": "개요", ...}, {"kind": "summary", "name": "요약", ...}, {"kind": "list", "name": "상세목록", ...}
  ]
}
```

문서와 셀에 새로 생기는 키
- 문서 `theme: "<이름>"` — 테마가 있으면 셀의 `s`(스타일 이름)를 그 테마에서 찾아 셀 키 아래에 깐다(셀 키가 이긴다). 테마를 바꾸면 모든 셀이 새 스타일로 바뀐다.
- 셀 `bd` 테두리 — `"line"`(팔레트 이름)·`"#BFC9D4"` 이면 네 변 가는 선, `{"t": 색, "r": 색, "b": 색, "l": 색}` 이면 변마다(없는 변은 선 없음).
- 탭 `grid: false` — 눈금선 숨김(표지·개요). 탭 `print: {"landscape": true, "fitWidth": 1}` — 인쇄 설정.
- 탭 `drawings: [{"type": "image", "src": "logo.png", "at": "B2", "dx": 0, "dy": 0, "w": 330, "h": 72}]` — 셀에 고정한 그림(px).
  `src` 는 테마 폴더 기준이거나 작업 공간 기준(`assets/...`)이고, `@brand/logo` 는 작업 공간 brand 로고다.

계산 규칙(스타일 풀기·팔레트 이름 → 색)은 화면(`sheet.js`)과 내보내기(`export_xlsx.py`) 두 곳에 있다. 테마 파일은 `sheet_theme.py` 가 읽는다.

**테마 미리 보기(0.25.11)** — 시작 페이지 템플릿 탭의 시트 테마 카드 [미리 보기], 새 시트 양식의 [미리 보기]
- 창 안에 **시트 화면 그대로**(`sheet.html?preview=<테마 키>&title=`) 테마로 만들 첫 시트(표지·이력·개요·요약·상세목록)를 보인다. 창에서 테마를 바꿔 보고 [이 테마로 새 시트] 로 양식에 고른다. 양식에 적은 제목이 표지 자리에 들어간다.
- 서버 `GET /api/sheet-preview?key=engine:<이름>|ws:<이름>&title=` 가 새 시트와 같은 탭(`sheet_theme.new_tabs`)을 **파일 없이** 만든다(`hub.sheet_theme_preview`). 그림은 `&f=<파일>`(테마 폴더 · 회사 테마의 작업 공간 `assets/…` · `@brand` = 그 작업 공간 brand 로고, 엔진 테마는 예제 자리 표시 로고). 시작 페이지 목록(`hub.sheet_themes`)에 있는 테마·그림 파일만 준다.
- 미리 보기 판은 고쳐 볼 수 있지만 저장·요청·세션·실시간 연결이 없다(그 밖의 API 를 부르지 않는다). 내보내기·세션·요청 패널 단추는 숨긴다.

**테마 만들기(샘플링)** — `python3 nexa.py sheet_theme import <샘플.xlsx> --name <이름>`
- 샘플 엑셀의 글꼴·주요 색(머리·라벨·테두리·입력칸·강조), 열 너비, 표지의 그림(로고)과 글 상자(과제명·문서명·날짜 자리)를 읽는다.
- 결과는 `assets/sheet-themes/<이름>/` 에 테마와 그림으로 만든다. Excel 이 있으면(Windows) 도형 묶음 로고도 그림으로 떠낸다. 만든 뒤 `theme.json` 을 사람이나 AI 가 다듬는다.

**엑셀 파일로 시작** — 시작 페이지 ＋ 새 시트 → "또는 엑셀 파일로 시작" 에서 .xlsx·.xlsm 을 고르면 테마 대신 그 파일이 첫 시트가 된다
(`init_workspace.py --kind sheet --sheet-import <파일>` → `sheet_import.py`). 값·수식·서식·병합·그림·매크로까지 옮기고 원본은 `materials/` 에 남는다.

## 6. 시트 → 슬라이드 연결

시트 범위를 슬라이드의 **표·차트**로 넣는다(편집기 ＋ 추가 → 데이터 → "시트에서 표·차트"). 요소에는 연결 정보와 지금 값이 함께 들어간다 - 렌더·PPTX 규칙은 그대로.

```jsonc
{"type": "table", "rows": [["지역", "매출"], ["서울", "1,200"]], "link": {"deck": "<시트 문서 id>", "tab": "t01", "range": "A1:B5", "as": "table", "header": true}}
{"type": "chart", "chart": "column", "categories": ["서울", …], "series": [{"name": "매출", "values": [1200, …]}], "link": {…, "as": "chart"}}
```

- 표는 **보이는 글**(표시 형식 반영 - `1,200`·`15.0%`·날짜), 차트는 첫 열 = 범주, 첫 줄 = 계열 이름, 나머지 = 계산값(수식은 계산해서).
- 편집기가 덱을 열 때 연결된 요소의 원본을 다시 읽어 바뀌었으면 맞춘다(실행 취소 한 번). 오른쪽 클릭 → 시트에서 새로 고침 · 원본 시트 열기 · 시트 연결 끊기(값은 남김).
- API `GET /api/sheet-range?deck=&tab=&range=&as=table|chart&header=1`, CLI `nexa.py sheet_link <시트> <탭> <범위> [--as chart]`(세션이 요소를 만들 때 - 결과 JSON 의 데이터와 link 를 그대로 요소에).

## 7. 개발 방향 (조사: [research/sheet-survey.md](research/sheet-survey.md) — M365 Excel · Google Sheets 기준)

기준 제품의 흐름도 우리와 같다. Excel 은 `=COPILOT()` 셀 함수를 2026-09 에 폐지하고 **사이드 패널 + 계획/적용**으로 옮겼다.
Gemini in Sheets 도 **미리보기 카드 → 적용 → 실행 취소** 로 움직인다. "범위를 고르고 → 요청 → AI 가 고치고 → 답(reply)" 은 지금 구조 그대로 그 방향이다.

원칙
- **두 곳 동일성**: 수식 계산과 표시 형식은 화면(JS)과 내보내기(Python) 두 곳에 생긴다. 함수는 천천히 늘리고, 같은 JSON 이면 같은 값·같은 표시 문자열인지 확인하는 `check_parity` 식 시트 시험을 둔다.
- **AI 가 쓴 수식도 계산된다**: 세션은 `f` 만 쓰고 `v` 는 비워도 된다. 내보낼 때 Python 평가기가 캐시 값을 채운다. XlsxWriter 는 캐시 값을 0 으로 쓰기 때문에, 뷰어·미리보기에서는 0 으로 보인다.
- **라이선스(MIT)**: 쓰지 않는다 — HyperFormula(GPL)·Handsontable 7+(상용)·Luckysheet(보관)·Univer Pro. 조건부로 쓴다 — Apache-2.0(Univer OSS·SheetJS CE)은 NOTICE 를 지키면 쓸 수 있다.
- **필터는 문서에 저장**(0.25.0 - 엑셀 자동 필터와 같다, 위 2절): 사람·AI·엑셀이 같은 필터를 본다. 예전의 "이 화면에서만" 필터 보기는 없앴다. 사용자별 필터 보기(Sheets 필터 보기)는 필요하면 따로 검토한다.
