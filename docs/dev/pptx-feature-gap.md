# PowerPoint 기능 중 미구현 목록 (적용 대상 판단용)

2026-10-16, 0.22.10 기준 코드 조사(0.22.11 에서 글 표기·문서 구조·도형·그림 묶음 적용 → 권장 열에 **완료** 표시; 표·차트 묶음은 0.22.12~)(`studio/export_pptx.py`·`common.py`·`render.js`·`studio.js`). PowerPoint 에서 동작하지만 이 엔진(편집기 + PPTX 내보내기)에 **없는** 기능을 모아, 무엇을 구현할지 고르기 위한 표다. 지원하는 것은 `docs/editor.md`·`docs/deck-format.md` 에 있다.

읽는 법:
- **작업**: 편집기(`render.js`·`studio.js`) 와 PPTX(`common.py`·`export_pptx.py`) 양쪽을 같이 고쳐야 하는지. 렌더 규칙은 두 곳에 같이 있다(`CLAUDE.md`).
- **권장**: 개발 세션의 의견 - **후보**(자료 품질에 바로 도움, 양쪽 구현이 정형적) · **보류**(쓸모는 있으나 비용 크거나 PowerPoint 외 뷰어 호환 문제) · **제외**(이 엔진의 방향 - 글·숫자 중심의 보고 자료 - 과 맞지 않음). 결정은 사용자 몫.
- 크기: S = 반나절, M = 하루 안, L = 며칠.

## 8. 권장 묶음(참고)

사용자 판단을 돕기 위한 묶음이다. 모두 편집기·PPTX 양쪽 동일성 검사(`check_parity.py -W example`)와 PowerPoint 렌더 대조를 거친다.

1. **글 표기 확장**(S×4): 취소선 · 위/아래 첨자 · 글자 단위 링크 · 일반 하이라이트 - `common.runs`·`render.js` 인라인 표기 한 곳에 모아 넣는다.
2. **표 강조**(S+M): 셀별 채움 · 구분선 - 상태 표·합계 행.
3. **차트 2종**(S+M): 누적 가로 막대·100% 누적 · 콤보(보조 축).
4. **문서 구조**(S×3): 섹션 자동 생성 · 문서 속성 · 숨김 슬라이드.
5. **도형·그림 마무리**(S×3): 도형 테두리 점선 · 그림 테두리 색/두께 · SVG 내보내기 결함 확인.

결정된 항목은 엔진 요청으로 등록해 처리한다(`docs/dev/engine-request-design.md`).
