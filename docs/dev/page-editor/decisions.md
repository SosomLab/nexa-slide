# 페이지 편집기 - 결정 기록

- **DR** = 확정(사용자 확정 또는 지시 판단) · **DP** = 추천안으로 진행 중, 사용자 확인 대기 · **D** = 미정(막히면 묻는다).
- 정정은 행을 고치지 않고 **새 행**으로 적는다(앞 행에 "→ DR-Pnn 로 대체"). 무인 진행 중 내린 판단은 DP 로 적고 근거를 한 줄 남긴다.
- 번호 점검(2026-11-27): DR-P01~P14 · DP-P01~P22 · D-P01~P05 - 빠짐·중복 없음. 표는 번호 순.
