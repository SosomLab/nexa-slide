# 편집기

Genspark AI Slides 작업 화면의 조작 방식(모드 3분할 · 그 자리 메모 · 붙박이 서식 줄 · 위치 조정 메뉴 · 확대 바닥줄)을 차용했다.
**슬라이드 디자인은 바뀌지 않는다** — 화면은 render.js, PPTX 는 export_pptx.py 가 기존 규칙 그대로 그린다.
화면 글은 한국어가 원문이고, 기본 메뉴(☰)의 **표시 언어**로 영어를 고르면 `studio/i18n.js` 사전으로 즉시 바뀐다(`docs/home.md` 표시 언어 절).

| 캔버스 | 확대(Ctrl+휠·슬라이더 10~300%·맞춤) · Space+끌기/가운데 버튼 = 화면 이동 · 요청 표시(번호 배지 + 테두리/영역) · 메모 팝오버 · **보낼 요청 바** |
| 아래 | **노트 · 개요 · 검사** 탭(같은 탭을 다시 누르면 접힘) · ◀ n / N ▶ · − 슬라이더 ＋ · 100% · ⤢ 맞춤 |
| 오른쪽 패널 | **속성**(모든 속성·요소 목록·요소 JSON) · **요청**(목록·상태·답변·슬라이드 전체 메모) · **기록**(자동 백업으로 되돌리기) |

색은 모두 **템플릿 토큰 팔레트**에서 고른다(색의 의미 유지 — 임의 HEX 입력 없음).

**요소 목록**(속성 탭 맨 아래, 가려진 요소 포함): 클릭 = 선택, **Ctrl+클릭** = 더하거나 빼기, **Shift+클릭** = 마지막으로 클릭한 요소부터 범위 선택(목록 순서). 캔버스의 Shift/Ctrl+클릭·범위 끌기와 같은 선택이 된다.
**적용 글꼴**(속성 탭): 글자가 있는 요소마다 "적용 글꼴" 줄에 실제 글꼴이 보인다 — 역할(본문/제목/코드 — `font` 또는 유형으로 정해짐: 코드·실행계획은 코드, 표는 `font`(본문 셀 기본)와 열별 `colFont` — 속성 탭 "유형"(일반 = 본문 글꼴 · 코드 = 고정폭 · 제목 글꼴)·"열별 글꼴"로 고친다) · 라틴 글꼴 + 한글 글꼴 · 크기(px = pt) · 굵게 · 어느 세트에서 왔는지(덱 글꼴 세트 → 작업 공간/템플릿 세트) · CSS 글꼴 이름. 이 브라우저에 그 글꼴이 없으면 경고(대체 글꼴로 보이는 중 — PPTX 는 받는 PC 의 글꼴).
**여러 요소에 한 메모**: Shift/Ctrl+클릭이나 범위 선택으로 요소를 여러 개 고른 뒤 오른쪽 클릭 "이 요소 n개에 요청 메모"(서식 줄 💬 도 같다) — 팝오버에 "요소 n개 (글자 e03, 원 e05 …)" 가 보이고, 요청은 `elements` 로 저장돼 캔버스에 요소마다 테두리, 요청 카드에 "e03 외 2" 로 보인다. 세션은 그 요소 모두를 대상으로 처리한다.

내보내기(PPTX·글꼴 포함 PPTX·PDF)로 받는 파일 이름은 **덱 제목**이다(못 쓰는 글자는 공백으로, 글꼴 포함은 `제목 - 글꼴 포함.pptx`). 작업 공간의 저장 위치는 전처럼 `out/<id>.pptx`·`.pdf`(렌더·비교 도구가 id 로 찾는다)이고 받을 때만 제목이 된다 — `out/` 을 직접 열어도 같은 이름으로 받아진다.

## 덱 관리

덱 탭에는 덱 **제목**(덱 안의 `title`)이 보이고, 덱 **id**(파일 `decks/<id>.json`)는 엔진이 만드는 짧은 해시(8자, 예 `d3f9a1c2`)다 - 사용자가 짓지 않고 탭 툴팁과 오른쪽 클릭 메뉴 머리에 표시만 한다(옛 덱의 손으로 지은 id 는 그대로 쓴다). 시작 덱(★)은 주소에 덱이 없을 때 편집기가 처음 여는 덱이다(작업 공간 설정 `nexa-slide.json` 의 `startDeck`).

- **＋**(덱 탭 끝): 새 덱 — 제목만 물어 표지 1장짜리 덱을 만들고 연다(id 는 저절로).
- 탭 **오른쪽 클릭**(맨 끝에 **새 덱**): **제목 바꾸기**(덱과 `content/<id>.json` 의 `title` — 다음 build 가 되돌리지 않게) · **복제**(새 id 로 덱 JSON 과 `content/<id>.json` 복사, 제목은 "… (복사)" 기본 - 요청·기록·첨부는 복사하지 않음) · **시작 덱으로 / 시작 덱 해제** · **덱 삭제(휴지통)**(덱·요청 `<id>.requests.json`·기록 `decks/.history/<id>/`·첨부 `out/attach/<id>/`·`content/<id>.json` 을 `decks/.trash/<id>-<시각>/` 로 — 웹 세션 턴이 도는 중에는 거절).
- 같은 일을 터미널에서: `python3 nexa.py deck list | create [<id>] [--title …] [--layout cover] | copy <id> [--title …] | start [<id>] | rename <id> <새 id> | retitle <id> "제목" | delete <id>`(`list` 의 ★ = 시작 덱, `rename` 은 CLI 에만 남긴다). API `POST /api/decks {action: create|copy|start|rename|retitle|delete, id, …}`, `GET /api/decks` 의 `start`.
- 덱 id 규칙: 영문·숫자·`-`·`_`(64자). `book` 은 통합본(`build_deck book`)용. PPTX 파일 이름(`out/<id>.pptx`)도 id 를 따른다.

메모는 **초안(draft)** 으로 쌓이고 캔버스에 번호 배지·레일에 ✎ 배지가 붙는다. 아래 바 **"요청 N개 보내기"** 로 한꺼번에 세션에 보낸다(초안 → 대기, 즉시 전달).
**후속 요청**: 요청 카드(대화의 마지막 요청)의 **[후속 요청]** 을 누르면 그 아래 입력칸이 열린다(앞선 답은 "앞선 답 보기"로 접어서 인용, ＋ 첨부·Ctrl+V 가능, Enter = 보내기, Esc = 닫기). 보내면 원 요청은 그대로 두고 같은 대상(슬라이드·요소·영역)의 새 요청이 바로 대기로 올라가 세션에 전달되며, 세션은 앞선 요청·답을 `context` 로 함께 받는다. 같은 대화는 요청 탭에서 한 묶음(왼쪽 연결선, 후속은 들여쓰기·"후속" 표시)으로, 썸네일 배지는 대화 단위로 하나만 센다. 아직 열린 요청의 답(질문)은 왼쪽 노란 줄로 보인다. "다시 열기"는 같은 요청을 다시 보낼 뿐이다 — 답을 달려면 후속 요청.
요청 탭의 슬라이드 요청 칸도 메모 팝오버와 같이 **Enter = 메모 남기기(초안)**, Shift+Enter = 줄바꿈이다(한글 조합 중 Enter 는 조합 확정만).
**요청 목록의 기본 보기는 최근 것만** — 최근 24시간에 진행(만듦·보냄·상태 변경·답, `updated`)된 요청과 아직 끝나지 않은 요청("이 슬라이드"/"최근 (n)"). 이전 것은 목록 위 **[더보기 · 이전 n]** 으로 여는 **요청 기록 창**에서 본다 — 서버 작업 목록처럼 별도 페이지로 가지 않고 편집 화면 **위에 겹쳐 뜨는 창**이라 편집 중인 덱·선택·저장 상태를 벗어나지 않는다(Esc·바깥 누름·✕ 로 닫음). 찾기(제목·내용·답·요소·첨부 이름, 일치 부분 강조, 대화 묶음 단위)·범위(전체/이 슬라이드)·상태(초안·대기·처리 중·완료) 필터, 카드의 "슬라이드 n" 링크를 누르면 창을 닫고 그 슬라이드로 간다. 완료/다시 열기/삭제는 창 안에서도 된다(후속 요청은 요청 탭에서). 찾기는 기본 **퍼지**(띄어쓰기·한두 글자 차이 허용 — "글머리기호" 로 "글머리 기호" 를 찾음)이고, **`#4`** 는 슬라이드 4 의 요청(`#4,5,7-10` 처럼 여러 장·범위, 다른 낱말과 같이 쓰면 그 슬라이드들 안에서 글 찾기)이며 입력칸 옆 토글 **Aa 대소문자 · ab 단어 단위 · .\* 정규식**은 일반 편집기의 찾기와 같다(브라우저에 기억, 공용 `studio/search.js`).
요청 탭 제목은 연결된 세션의 에이전트에 따라 **Claude/Codex 에게 요청**, 세션이 없으면 **AI 에게 요청**이고, 세션이 없는데 대기 요청이 있으면 "세션이 꺼져 있어 처리되지 않습니다 — 웹 세션 시작…" 경고가, 마지막 웹 세션이 서버 재시작·유휴로 끝났으면 그 사유와 시각이 안내 줄·칩 툴팁·칩 메뉴에 보인다.
**첨부**: 메모 팝오버·요청 탭 입력칸에 클립보드 그림을 **Ctrl+V** 로 붙여 넣거나, 파일을 끌어다 놓거나, **＋ 첨부** 버튼으로 고르면 바로 올라가 축소판 칩으로 보인다(✕ 로 뺌). 메모를 남기면 요청에 담기고 목록에서도 축소판이 보인다. 축소판·파일 이름을 누르면 **새 창 대신 화면 위 미리보기(라이트박스, `studio/lightbox.js`)** 가 뜬다 — 같은 요청의 첨부를 ◀ ▶·← → 키·스와이프·아래 축소판 줄로 넘기고("2 / 5"), "이 슬라이드의 모든 요청 첨부" 토글로 범위를 넓힐 수 있다. 휠 확대·끌어 이동·두 번 누르기(맞춤/원본), Esc·바깥·✕ 닫기, [원본 열기]·[내려받기]. PDF 는 그 안에서 iframe, 다른 문서는 아이콘 카드 + [열기]. 올려 둔 칩(아직 보내지 않은 첨부)과 시작 페이지 서버 작업 카드의 요청 첨부도 같은 미리보기를 쓴다.
세션은 그 파일을 읽어 반영한다(그림은 내용을 보고). 그림·PDF·글·pptx/docx/xlsx, 12MB 까지, 작업 공간 `out/attach/<덱>/` 에 저장(git 제외) — [claude-session.md](claude-session.md) 2절.
"취소"는 이 슬라이드에 초안이 있으면 그 슬라이드만, 없으면 전체 초안을 지운다. 슬라이드를 넘겨도 초안·바는 유지된다.
아직 "메모 남기기"를 누르지 않은 입력(요청 탭의 슬라이드 요청 칸, 요소 메모 팝오버)도 덱·슬라이드·요소별로 브라우저에 보관된다 - 다른 슬라이드에 갔다 오거나 새로 고쳐도 남아 있고, 메모를 남기면 지워진다. 영역(그리기) 메모는 보관하지 않는다.

**✨ 레이아웃 고치기** = 이 슬라이드의 검사 결과를 담아 바로 요청(기존 디자인 유지 · 요소를 지워 경고를 없애지 말 것), **✨ 다듬기** = 스타일 유지하며 내용 논리·정렬 정리 요청. 둘 다 초안을 거치지 않고 바로 보낸다.

## 표 - 렌더 표와 표 객체, 셀 선택 (0.22.17)

- **렌더 표**(`table`)는 글(`줄 = 행, | = 칸`)에서 자동으로 그리는 표, **표 객체**(`table-obj`)는 셀마다 서식을 갖는 PowerPoint 식 표다(＋ 추가 → 표 객체). 서식 줄 **⇄ 객체 / ⇄ 렌더**(속성 탭·오른쪽 클릭에도)로 서로 바꾼다 - 렌더 표 → 표 객체는 글·채움·병합·열 글꼴·정렬·행 높이를 그대로 옮기고, 표 객체 → 렌더 표는 셀·행 단위 글자 서식을 버린다(무엇을 버렸는지 안내).
- **셀 선택**: 표를 고른 뒤 표 안을 다시 누르면 셀 하나, 끌면 범위, <kbd>Shift</kbd>+클릭 범위, <kbd>Ctrl</kbd>+클릭 더하기/빼기(가장자리 6px 안쪽을 끌면 표 이동). 방향키 = 셀 커서(<kbd>Shift</kbd> 범위), <kbd>Tab</kbd>/<kbd>Shift</kbd>+<kbd>Tab</kbd> 옆 셀(마지막이면 행 추가), <kbd>Delete</kbd> 비우기, <kbd>Enter</kbd>·두 번 클릭 = 그 셀만 글 편집(<kbd>Tab</kbd> 으로 다음 셀), <kbd>Esc</kbd> 선택 해제.
- **표 이동·크기**: 표를 고르면 바깥에 점선 띠와 왼쪽 위 **✥ 손잡이**가 생긴다 - 끌면 표가 움직인다(<kbd>Alt</kbd>+끌기도 이동). 위·왼쪽의 얇은 **띠**는 열·행 전체 선택(끌면 여러 줄, <kbd>Shift</kbd> 범위, <kbd>Ctrl</kbd> 더하기), 안쪽 **열·행 경계**를 끌면 이웃 폭·높이가 바뀐다. 서식 줄·속성의 **↕ 글에 맞춤**은 글 양에 맞춰 행 높이를 다시 나눈다. 속성 **줄무늬**는 본문 둘째 행부터 한 줄 걸러 바탕. **표 안 오른쪽 클릭**은 그 셀(또는 고른 범위) 기준 메뉴 - 행 위/아래·열 왼쪽/오른쪽 삽입, 행/열 삭제, 셀 병합/풀기, 셀 비우기, 셀 서식 지우기, 셀 글 편집, 행/열/표 전체 선택, ↕ 행 높이 맞춤. **고른 열·행의 띠**(파란 표시)를 끌면 놓을 자리가 파란 선으로 보이고 놓으면 그 자리로 순서가 바뀐다(서식·병합도 같이 이동, Ctrl+Z 되돌리기).
- **셀 서식 줄**(셀을 고르면): 🪣 채우기 · A 글자색 · B 굵게 · I 기울임 · 가로 3 · 세로 · 크기 · ▢ 테두리(모든 변·위·아래·왼쪽·오른쪽·굵은 위 선·지우기) · ⊞ 병합/풀기 · ＋행↓ －행 ＋열→ －열(고른 셀 기준). 렌더 표에서 채움·테두리·병합은 덧씌우기로 남고, 글자 서식(색·굵게·기울임·크기·세로·가로)을 넣으면 표 객체로 바뀐다(안내 토스트, Ctrl+Z 로 되돌림).

**＋ 새 슬라이드**(왼쪽 레일 맨 아래 - **맨 마지막**에 추가) 또는 썸네일 오른쪽 클릭 메뉴 "아래에 새 슬라이드"(**그 슬라이드 다음**에 추가)를 누르면 **슬라이드 추가** 창이 열린다. 맨 위 **빈 슬라이드**는 템플릿 기본 항목(로고 · 바닥 경로 · 워드마크 · 쪽번호)만 있는 장이다(레이아웃 `blank`).
- **유형으로**: 목적별 8묶음(시작·도입 · 메시지 · 근거·데이터 · 비교·판단 · 과정·계획 · 사람·사례 · 학습·확인 · 마무리·부록)의 슬라이드 유형 52개를 미리보기 카드로 고른다. 찾기 칸으로 거른다.
  고른 유형은 그 목적에 맞는 예시 내용이 채워진 채 지금 슬라이드 다음에 들어간다(Ctrl+Z 로 되돌리기). 목록 [slide-types.md](slide-types.md).
- **레이아웃으로**: 예전처럼 레이아웃 이름으로 고른다(필드 예시 내용).
- **유형 바꾸기**: 썸네일 오른쪽 클릭 → "유형 바꾸기" — 같은 창에서 고른 유형으로 **이 장을 바꾼다**. 제목 글자·노트·슬라이드 id 는 남기고 본문은 새 유형의 예시 내용으로(Ctrl+Z 로 되돌리기).

슬라이드 속성(오른쪽 패널)에서 **이 장 글꼴**(이 장만)·**덱 글꼴**(덱 전체) 세트를 고를 수 있다 — 우선순위·규칙은 [fonts.md](fonts.md).

## 코드 요소

- **언어**: 속성 탭 "언어" 칸에 입력하면 목록이 좁혀진다(이름·별칭 - sh, cs, js, py, rs …). 서식 줄의 언어 단추(예: "SQL ▾")는 찾기 칸이 있는 메뉴, Enter = 첫 항목. 35종 - Bash · PowerShell · C · C++ · C# · Java · Kotlin · Scala · JavaScript · TypeScript · JSON · YAML · INI/TOML · HTML/XML · CSS · SCSS/Less · Markdown · Diff · Python · Ruby · Perl · PHP · Go · Rust · Swift · Dart · Objective-C · VB.NET · Lua · R · GraphQL · Makefile · Dockerfile · SQL · 일반 글자.
- **언어 표시**: 캔버스의 코드 블록 오른쪽 위에 언어 이름표(예: SQL). 언어를 고르지 않았거나 "일반 글자"면 표시하지 않는다. 편집 화면에만 보이고 슬라이드·발표·PPTX 에는 들어가지 않는다. 속성 탭 언어 칸 옆 **표시** 스위치 또는 ⋯ 더보기 → "코드 언어 이름표 표시"로 끄고 켠다(기본 켜짐, 모든 코드 블록 공통, 브라우저 기억).
- **줄 번호**: 스위치 켜기/끄기(`lineNo: false`) - 숨기면 번호 열 없이 코드가 왼쪽부터. PPTX 도 같다.
- **복사**: 속성 탭 "📋 복사" 또는 서식 줄 📋 - 코드 글자만(줄 번호·색 없이) 클립보드로.
- 여러 코드 요소를 함께 골랐으면 언어·줄 번호는 모두에 적용.

## 여러 요소 · 패널 크기

- **여러 요소 고르기**: <kbd>Shift</kbd>/<kbd>Ctrl</kbd>+클릭으로 더하거나 빼기, 슬라이드의 빈 곳을 끌어 **범위 선택**(상자 안에 완전히 들어간 요소), <kbd>Ctrl</kbd>+<kbd>A</kbd> 이 장의 잠기지 않은 요소 전체, 속성 탭 요소 목록에서도 Shift/Ctrl+클릭. <kbd>Esc</kbd> 해제.
- **함께 이동**: 고른 요소 하나를 끌면 모두 같은 만큼(잡은 요소 기준 격자 맞춤), 방향키도 모두. 잠긴 요소는 움직이지 않는다.
- **공통 속성**: 서식 줄(글자 크기·글꼴·색·굵게·정렬·줄 간격·채우기·테두리·선 모양·잠금)은 그 속성이 있는 요소 모두에 같은 값으로. 속성 탭에서 고친 값은 같은 종류 요소 모두에(위치·크기는 선이 아닌 모든 요소, 잠금은 전체, 글자 내용은 주 선택만).
- **✥ 위치 조정**(여러 개일 때): 선택 묶음 기준 왼쪽·가운데·오른쪽·위·가운데·아래 맞춤, 가로·세로 같은 간격 분배(3개 이상), 주 선택과 같은 너비·높이·크기, 맨 앞·맨 뒤(상대 순서 유지).
- 복제(<kbd>Ctrl</kbd>+<kbd>D</kbd>)·복사/잘라내기/붙여넣기·삭제도 고른 요소 모두. 크기 조절 손잡이는 하나만 골랐을 때만.
- **최대화 배치**: 아래 줄 "⤢ 맞춤" 옆 **⛶ 최대화** - 노트·개요·검사 탭과 패널을 오른쪽 패널 아래로 옮기고 가운데를 슬라이드에 쓴다(슬라이드 자동 맞춤). 그동안 단추는 **🗗 복원**으로 바뀐다. <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>M</kbd> 으로도 오간다. 상태는 브라우저에 기억, 오른쪽 패널을 숨기면 먼저 복원한다.
- **패널 크기**: 왼쪽 썸네일 레일·아래 노트/개요/검사 패널·오른쪽 속성 패널의 경계를 끌어 조절하고, 두 번 클릭하면 처음 크기. 크기가 바뀌면 슬라이드를 새 영역에 맞춰(확대 "맞춤") 다시 그리고 썸네일도 새 폭에 맞춘다. 크기는 브라우저에 기억(⋯ → 편집기 화면 배치 초기화로 되돌림). 아래 패널 기본 높이는 98px.

## 기록 · 발표 · 저장

- **기록**: 편집기 저장 때마다·build 덮어쓰기 전·밖에서 바뀌기 직전에 남긴 자동 백업 목록(최근 50개). "되돌리기"는 그 시점 덱으로 바꾸고 저장한다(지금 상태도 기록에 남고 Ctrl+Z 로 취소 가능). 무엇이 바뀌었는지는 **변경** 탭.
- **발표**: F5 처음부터 · Shift+F5 현재부터 · →/Space/클릭 다음 · ← 이전 · **N = 노트·경과 시간** · Esc 끝(마지막 슬라이드로 편집기 이동).
- **자동 저장**: 편집 0.7초 뒤. **바뀐 것이 없으면 저장하지 않는다**(기록에 빈 저장이 쌓이지 않게). 2초마다 파일 버전 확인 → 밖에서(Claude) 바꾸면 자동 다시 불러오기(편집 중이면 충돌 선택).
- **새 덱·설정·엔진 변경**: 같은 2초 확인으로 작업 공간 전체를 본다 — 보고 있는 슬라이드와 상관없이 머리 아래 파란 안내 띠로 알린다.
  - 덱이 생기면(예: Claude 에게 덱 추가를 요청) 덱 탭을 바로 갱신하고 "새 덱 N개 — [열기]". 새로 고침은 필요 없다.
  - 보고 있던 덱 파일이 없어지면 [새로 고침].
  - 작업 공간 설정(`nexa-slide.json` - 템플릿·글꼴·로고·제목)이 바뀌면 다시 불러와 바로 적용한다(안내 없음).
  - 편집기 코드·템플릿 파일(엔진)이 바뀌면 [새로 고침](편집 중이면 저장하고 새로 고침).
- **변경(원장)**: 편집기·Claude·빌드·외부에서 덱이 바뀔 때마다 서버가 원장(`decks/.history/<덱>/changes.jsonl`, 덱당 1,000건)에 남긴 것을 보여 준다 - [change-ledger.md](change-ledger.md).
  - 머리: 제목 오른쪽 ⓘ = 설명 보기/숨기기(바깥을 누르면 닫힘), 색 필터 칩(툴팁에 대상 설명), 같은 폭 단추 셋.
  - 출처 배지(필터 칩과 같은 글자): 편집(현재 편집기) · 협업(다른 편집기) · AI(정확 / 추정 - 점선, 툴팁에 근거) · 빌드 · 외부. 필터 전체·편집(현재 편집기)·협업(다른 편집기)·AI(Claude 세션)·빌드·외부.
  - **최근 수정 대상**: 슬라이드별로 마지막에 그 장을 건드린 변경(출처·상대 시각·종류). 누르면 그 장으로.
  - 묶음 목록: 같은 출처·같은 창에서 60초 안에 이어진 저장은 한 묶음("저장 N회(요약)"). 장마다 수정·추가·삭제·이동(순서 a → b), 요소마다 바뀐 종류(글자·위치·크기·모양·그림·추가·삭제)와 글자 전 → 후. 누르면 그 장·요소로 간다. **직전으로** = 그 변경 직전 백업으로 되돌리기(백업이 남아 있을 때만).
  - 안내 띠 "다시 불러왔습니다 - Claude · 1장 수정 [변경 보기]". 확인하지 않은 변경(내 편집 포함)은 썸네일·개요에 "변경" 배지, 캔버스에 파란 점선. **확인함**(지금까지를 미표시로) · **최근 3개 표시**(최근 묶음 3개를 표시) · **표시 끄기/켜기**(기록을 보지 않고 작업), 묶음마다 **숨기기/표시**.
  - 이동은 순서가 유지된 가장 긴 흐름 밖의 장만 센다(한 장을 옮기면 사이에 밀린 장은 이동으로 치지 않는다). 비교 규칙은 서버 `deckdiff.py` 한 곳.

## 화면 ↔ PPT 일치 규칙 (검증 결과)

- 글자: 한 줄 = 한 단락, 줄 간격 "정확히 size × lineHeight × 0.75 pt". PowerPoint 는 여분 줄 높이를 위 75%·아래 25%로 두므로
  브라우저 글자를 `fonts.pptTextShift`(서버가 글꼴 파일의 세로 메트릭으로 계산한 보정값, shift = size × (0.355 × lineHeight − 0.362 × C), C = (winAscent+winDescent)/unitsPerEm) 만큼 내려 맞춘다 — Pretendard·KoPub돋움체·JetBrains Mono 를 PowerPoint 렌더와 대조해 크기 16~44px, 줄 높이 1.0~1.6 에서 오차 ±1px(`studio/tests/shift_bench.py`).
- 둥근 사각형·타원의 PPT 글자 영역은 도형 안쪽으로 들어가 있어(반경 × 0.29289, 타원 14.6%) 그만큼 여백에서 뺀다.
- 한국어 줄바꿈: 두 쪽 모두 어절 단위(`word-break: keep-all` ↔ PowerPoint 기본). 긴 문장은 `\n` 으로 직접 끊는 것이 가장 안전하다.
- `python3 studio/compare.py ch00`: 샘플 덱 15장 모두 픽셀 차이 0.3~2.7%(글자 가장자리 안티앨리어싱 수준). 비교 이미지 `out/ch00/compare-NN.png`
- `python3 studio/check_parity.py ch00`: 코드 색·인라인 강조·plan 강조·표 격자의 JS/Python 결과 동일

## 알려진 한계

- 표 머리 행의 둥근 모서리(concept 의 `th` 반경)는 PPT 표가 지원하지 않아 양쪽 모두 직각으로 그린다.
- PPT 표는 글자가 칸보다 크면 행이 저절로 늘어난다(브라우저는 넘쳐 보임). `plan-table` 콜아웃은 행 높이 고정을 전제로 놓이므로 행이 늘면 어긋날 수 있다.
- `plan` 강조의 배경색은 run 강조색(`a:highlight`)이다 — PowerPoint 2019/365 에서 보이고, 이전 버전·다른 뷰어에서는 글자색 + 굵게만 보일 수 있다.
- 줄 배치 보정은 글꼴 파일(`measure.regular`)의 메트릭으로 계산하므로 어느 글꼴 세트든 적용된다. 글꼴 파일을 찾지 못하면(설치도 작업 공간 `fonts/` 에도 없음) 평균 메트릭(1.2)으로 계산해 ±2px 정도 어긋날 수 있다 — 그 글꼴 파일을 `fonts/` 에 두면 된다. 고정폭 코드 안의 한글(D2Coding 등 대체 글꼴)은 라틴 글꼴 메트릭 기준이라 ±2px.
- 글자 자동 맞춤(넘치면 줄이기)·그라데이션 편집은 지원하지 않는다(그라데이션은 요소 JSON 으로만). 회전·그림자·투명도·다중 선택·정렬 맞추기는 지원한다(0.21.29~).
- 다른 PPTX 를 덱으로 가져오기: `python3 nexa.py import_pptx <파일> --deck <새 덱 id>` — 글·글머리(번호·기호 유지)·표·그림(`assets/import/<id>/`)·차트·프리셋 도형을 원본 위치·크기로 넣는다(색·글꼴은 템플릿 기본). 이미 있는 덱 이름이면 `--force`.
- PPT 에서 사람이 고친 내용은 덱 JSON 으로 돌아오지 않는다(단방향). 수정은 편집기나 JSON 에서 한다. 다른 PPTX 의 내용을 덱으로 옮길 때는 `nexa.py import_pptx <파일>` 로 글·표·차트·노트·그림을 꺼내(`out/import/<이름>/`) 세션이 읽어 쓴다([claude-session.md](claude-session.md) 2절).
- 새 슬라이드(레이아웃)는 자리 표시 내용으로 만들어진다 — 내용은 요소를 고치거나 `content/` 에 쓰고 build 한다.
- SVG 그림은 PPTX 에 PowerPoint 2016+ 의 SVG 그림으로 들어간다(이전 PowerPoint·다른 뷰어는 대체 PNG 를 보이는데, 옆에 같은 이름 `.png` 가 없으면 빈 그림). 글자 단위 링크(`[[link:…|글]]`)의 글자색 유지는 Office 2019+ 확장(`hlinkClr`)이라 이전 버전은 테마 링크색(파랑)으로 보인다. 형광펜(`[[bg:…|글]]`)은 `plan` 강조와 같이 PowerPoint 2019/365 에서 보인다.
- 표·차트는 묶음(Ctrl+G)에 넣을 수 없다 - PPTX 묶음 도형이 표·차트를 담지 못하므로 편집기가 막는다(안내).
- 동시 편집: 한 덱을 브라우저 두 곳에서 열면 늦게 저장한 쪽이 충돌 알림을 받는다(자동 병합 없음).
