# 슬라이드 유형 — 목적·구성으로 고르는 낱장 54개

색·배치가 아니라 **이 장이 하는 일**(목적·구성)로 나눈 낱장 목록이다. 목록 파일 `studio/slide_types.json`(`layout` = 그리는 레이아웃, `fields` = 예시 내용, `when` = 고를 신호).

## 선별 기준 — 초안·요청 처리에서 쓰는 법

1. 장마다 **내용 성격**을 먼저 정한다 — 결론 숫자 하나인가, 추이인가, 대안 비교인가, 결정 요청인가, 사례인가, 풀이인가.
2. 그 성격과 `when`(고를 신호)이 맞는 유형을 고른다: `python3 nexa.py slide_types [낱말]`(예: `slide_types 추이`, `slide_types 결정`).
3. 유형의 `layout` 과 필드 구조로 `content/<덱>.json` 에 쓴다(필드 형식 `nexa.py layout_samples <레이아웃>`, 예시 내용 `slide_types --json <낱말>`).
4. 덱 전체 흐름은 템플릿 유형의 대표 장 흐름(시작용 내용)을 따른다 — 예: 정기 보고 = KPI → 추이 → 상태 → 막대 → 리스크 → 다음 행동.
5. 사용자가 "이 장을 ~처럼" 요청하면 같은 기준으로 유형을 바꿔 다시 쓴다(요소 id 는 새로 — 편집기 변경 탭에 남는다).

편집기에서는 **＋ 새 슬라이드 → 슬라이드 추가 창 → 유형으로**에서 미리보기를 보고 골라 넣는다. 검토·승인은 시작 페이지 **슬라이드 유형 검토**(`/review/slides`).
근거: Genspark 공개 슬라이드 스킬 2,274장 전수 조사([research/genspark-skills/03-slide-archetypes.md](research/genspark-skills/03-slide-archetypes.md)). 새 레이아웃 19종은 `studio/layouts_more.py`.
