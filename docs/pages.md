# 페이지(워드) — AI 와 함께 쓰는 글 문서

> 세 번째 문서 종류(PG-090 · 2026-11-26 숨김 해제 - 기본으로 보인다). 슬라이드·시트와 같은 방식(편집기에서 보고 고치고, 요청 → 세션이 파일을 고침 → done + reply)으로
> Word · Pages 같은 글 문서를 함께 만든다. 편집 원본은 nexa-slide 안의 JSON 이고, Word(.docx)·PDF 는 산출물(내보내기)이다.
> 설계 = [dev/page-editor/design.md](dev/page-editor/design.md) · 결정 = [dev/page-editor/decisions.md](dev/page-editor/decisions.md) · 지금 상태 = [dev/page-editor/STATUS.md](dev/page-editor/STATUS.md)

## 1. 무엇인가

| | 슬라이드 | 시트 | **페이지** |
|---|---|---|---|
| 덱 JSON | `slides` | `"kind": "sheet"` · `sheets` | `"kind": "page"` · `blocks`(흐르는 본문) · `page`(쪽 설정) · `styles` |
| 편집 화면 | `index.html` | `sheet.html` | `page.html` |
| 내보내기 | PPTX | XLSX | **DOCX** · PDF(Word 로 변환 / 화면 그대로) |
| 가져오기 | - | xlsx | **docx**(Word 문서) |

본문은 장이 없는 블록 목록이다 - 문단(글 조각 `runs`)·표·그림·쪽 나누기. 쪽은 용지·여백대로 **종이 장마다 나뉘어** 보이고(실시간 쪽 나눔 - 긴 문단은 줄 사이, 표는 행 사이에서 나뉘고 표의 머리글 행은 다음 쪽 머리에 되풀이된다. 쪽 번호·머리말·꼬리말은 쪽마다),
인쇄·PDF·Word 에서 실제 쪽이 된다. 저장·버전·충돌 배너·백업·변경 원장(`.history/<id>/`)·요청은 슬라이드와 같다.

## 2. 기본 켬 · 끄는 법

2026-11-26 숨김을 풀어(사용자 결정 · decisions.md DR-P13) **따로 끄지 않으면 켜져 있다** - 새 문서 대화 상자·홈에 "페이지" 가 보이고 만들기 API 가 받는다.
끄면 예전 숨김 상태와 같다(새 문서 대화 상자·홈에 "페이지" 가 없고 만들기 API 는 400). 이미 있는 페이지 문서 파일은 그대로 남는다.

| 어디서 | 끄는 법 | 다시 켜기 |
|---|---|---|
| 작업 공간 서버 | 작업 공간 `nexa-slide.json` 에 `"experimental": {"page": false}` | 그 줄을 지우거나 `true` |
| 허브(홈 · 첫 문서 고르기) · 작업 공간 서버 | 환경 변수 `NEXA_SLIDE_EXPERIMENTAL=-page`(쉼표로 여러 개, 작업 공간 설정보다 먼저 본다) | 변수를 지우거나 `page` |

판단 순서: 환경 변수(`-page` = 끔 · `page` = 켬) → 작업 공간 `experimental.page` → 둘 다 없으면 숨김을 푼 기능 목록(`RELEASED`)에 있으니 켬.
CLI 는 `deck_admin create --kind page` · 첫 문서 `init_workspace --kind page`.

편집 화면은 `page.html?deck=<id>` 이고, 슬라이드 · 시트 편집기에서 페이지 id 를 열면 `page.html` 로 넘어간다(반대도 같다).

## 3. 만들기

- **새 문서 대화 상자**: 슬라이드 덱 탭의 [＋] · ☰ 메뉴 · 페이지 화면의 문서 목록 → 새 문서. 종류(슬라이드 · 시트 · 페이지)를 고르고 템플릿을 고른다(자주 쓴 템플릿이 앞에).
- **홈**(`#new`): 첫 문서로 페이지를 고를 수 있다.
- **템플릿 11종**(만들 때 `{title}`·`{date}` 를 채운다 - 머리말까지):

| 묶음 | 템플릿 |
|---|---|
| 일반 | 빈 문서 · 보고서 · 기획서·제안서 · 회의록 · 공문·레터 · 매뉴얼·안내서 · 이력서 · 논문·리포트 |
| 학습 | 해설지(지문 분석 - 왼쪽 67% 지문 + 윗주, 오른쪽 33% 어휘·해석) · 문제지 · 어휘 정리 |

  템플릿의 글꼴·색은 작업 공간 토큰(`tokens.json` 의 `body`·`title` 글꼴, `accent`·`ink`·`muted` 색)을 따른다.
- **Word 문서 가져오기**: 새 문서 대화 상자의 [Word 문서(.docx)에서 가져오기] 또는 `POST /api/decks {action:"import", name, data}`.
- **Word 파일을 요청에 첨부**: 요청 패널에 .docx 를 첨부하면 세션이 분석(`import_doc`)하거나, 내용을 이 문서에 서식째 넣는다(`import_docx --blocks` - 새 문서를 만들지 않고 블록만 꺼낸다, [claude-session.md](claude-session.md)).
  제목·스타일·글자 서식·목록·표(합친 칸 포함)·그림·쪽 나누기·머리말·꼬리말·쪽 번호를 옮긴다. 글 상자의 글은 문단으로 꺼내고,
  옮기지 못한 것(각주·미주·떠 있는 개체 등)은 경고로 알려 준다.

## 5. 표

- 칸을 **오른쪽 클릭**하면 칸 메뉴: 위/아래에 행 넣기 · 왼쪽/오른쪽에 열 넣기 · 행/열 지우기 · 오른쪽 칸과 합치기 · 아래 칸과 합치기 · 칸 나누기 · 머리글 행 · 칸 채우기(회색) · 테두리 없음(배치용 표) · 칸 사이 세로선만 · 표 지우기.
- **배치용 표로 2단 만들기**: 칸 하나짜리 행에 너비가 다른 칸 둘(예 67 : 33)을 두고 "테두리 없음" 또는 "칸 사이 세로선만" 을 고른다.
  편집 중에는 칸 경계가 흐린 점선으로 보이고, 인쇄 · PDF · Word 에서는 선이 없다(세로선만이면 칸 사이 선 하나).
  Word · Pages 에 그대로 테두리 없는 표로 나가므로 받은 쪽에서도 같은 모양이다. 해설지 템플릿이 이 방식이다.

### 도형 · 글 상자

[도형] 단추 → 글 상자 · 사각형 · 둥근 사각형 · 타원 · 선 · 화살표 · 괄호. 커서가 있는 문단(없으면 화면 맨 위 문단)에 **매여** 그 문단이 놓인 쪽에 뜬다.

- 끌어 옮기고, 오른쪽 아래 손잡이로 크기를 바꾼다. 다른 쪽으로 끌면 그 쪽의 문단에 다시 매인다. 매인 문단이 지워지면 가까운 문단에 다시 매인다.
- 오른쪽 클릭: 채움 · 선(종류 · 굵기 · 색) · 글 뒤로 · **문단을 따라 움직임**(문단 기준 자리 - 문단이 움직이면 같이) · 지우기(Delete). 글 뒤로 보낸 것은 Alt+클릭으로 고른다.
- 글 상자 안의 글은 표 칸처럼 편집한다. Word 로 내보내면 떠 있는 도형(`wp:anchor`)이 된다.

## 6. 내보내기 · 인쇄

| 메뉴 | 결과 |
|---|---|
| 내보내기 → Word 문서(.docx) | `out/<제목>.docx` 내려받기. 스타일 · 목록 번호 · 표 병합 · 윗주 · 음영 · 머리말 · 쪽 번호가 Word 기능으로 나간다 |
| 내보내기 → PDF(Word 로 변환) | 이 서버 PC 에 Word 가 있으면 Word 가 만든 PDF(매크로 끔 · 읽기 전용). 없으면 화면 그대로로 안내 |
| 내보내기 → PDF(화면 그대로) | 브라우저(Chrome) 인쇄 엔진으로 만든 PDF(`?via=chrome`) |
| 인쇄 | 브라우저 인쇄(도구 막대 · 화면의 쪽 나눔 빈 자리 · 도형은 빠지고 쪽은 브라우저가 나눈다 - 화면과 같게 하는 일은 다음 단계) |

API: `POST /api/export/<id>`(DOCX) · `?pdf=1`(Word 우선, Word 가 없거나 실패하면 서버의 Chrome/Edge 인쇄 - 둘 다 안 되면 501 `needPrint`) · `?pdf=1&via=chrome`(Chrome 만).

## 7. 동시 편집

두 창(사람 · AI 세션)이 같은 문서를 고치면 저장할 때 **블록(문단 · 표의 행 · 칸) 단위로 합친다**(`PUT ?base=&merge=1`, 슬라이드 · 시트와 같은 병합기).
서로 다른 문단을 고친 것은 둘 다 남고, 같은 문단의 글을 둘 다 고치면 충돌로 알려 준다. 작업 저장(`POST /api/ops`)은 페이지 문서에 쓰지 않는다(400 - 화면은 통째 병합 저장).

**알려진 한계**:
- 두 창이 동시에 문단 **순서**를 바꾸면 나중에 저장된 쪽의 상대 순서가 남는다(슬라이드 · 시트와 같은 규칙).
- 문단 음영은 Word 에서 본문 여백보다 조금 바깥까지 칠해진다(Word 의 문단 음영 동작).

## 8. AI 요청

머리 막대의 **[AI 요청]** 으로 오른쪽 요청 패널을 연다(처음에는 접혀 있고, 연 상태를 기억한다).

1. 본문에서 고칠 문단을 고른다(여러 문단을 걸쳐 고르면 그 블록들, 표 칸 안이면 그 표). 패널 위 "대상"에 보이고, 요청 칸으로 가면 본문의 그 블록이 표시된다. **문서 전체**를 체크하면 범위 없이.
2. 요청을 적어 [보내기] - 먼저 저장한 뒤 요청이 생긴다. 세션이 연결되지 않았으면 저장만 되고 패널 안내에 "세션 연결 없음"이 보인다(세션 칩에서 웹 세션 시작).
3. 세션이 처리하면 카드에 답(`reply`)이 보이고 문서가 다시 읽힌다. 카드를 누르면 그 블록으로 간다. 카드의 [후속 요청] 으로 이어서 묻는다(앞선 요청과 답이 함께 간다).

처리 규약은 슬라이드와 같다(`working` → 덱 수정 → `done` + `reply`, [claude-session.md](claude-session.md)). 요청의 대상은 블록 id 로 온다 - `slide` = `element` = 첫 블록, 여러 블록이면 `elements`(목록), 문서 전체면 셋 다 없다. 페이지 문서에는 제안 저장(`--propose`)을 쓰지 않는다.
세션이 알아야 할 형식(요약 - 원문은 `studio/agents/turn_prompt.md` 의 페이지 문단):

- 문단 `{"id", "type": "p", "runs": [{"t": "글", "b", "i", "u", "c": "accent", "hl": "#fff59d", "size": 12, "link"}], "style": "h1", "align": "center"}`
- 표 `{"type": "table", "cols": [30, 70], "rows": [{"id", "head": true, "cells": [{"id", "colspan": 2, "blocks": [문단 …]}]}]}` · 그림 `{"type": "image", "src", "w": 80}` · 쪽 나누기 `{"type": "break"}`
- 서식은 `runs` 의 키로만(글 안에 `**굵게**` 쓰지 않음) · 제목은 `style` 로(크기를 직접 키우지 않음) · 목록은 문단 속성 `"list": {"kind": "bullet"|"number"|"check", "level": 0}`(번호를 글에 적지 않음)
- 새 블록 `id` 는 비워도 된다 · 있던 블록 `id` 는 바꾸지 않는다(병합 · 변경 기록이 id 로 찾는다) · 쪽 설정은 `page`
- 저장은 `save_deck`(형식이 틀리면 이유를 알려 준다). 내보내기는 사용자가 편집기에서 한다.
