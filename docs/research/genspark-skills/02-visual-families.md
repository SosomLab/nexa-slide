# 02. 시각 계열과 템플릿 후보

> 근거: 156개 스킬을 시각 검토자 8명이 나눠 보고 붙인 시각 계열 60여 개를 9개 묶음으로 정리했다(`data/census.json` 의 `family`·`familyGroup`·`tone`·`grid`·`score`·`why`).
> 색은 역할·색상 계열로만 적는다. nexa 템플릿을 만들 때 색 값과 글꼴은 새로 정한다(글꼴은 무료 글꼴 - [../../fonts.md](../../fonts.md)).

## 1. 지금 nexa 템플릿과의 차이

지금 템플릿 8종(`lecture` 와 그 바탕의 `report`·`brief`·`story`·`notice`·`schedule`·`proposal`·`lecture-large`)은 **같은 배치에 색·모서리만 바꾼 것**이다.
Genspark 에서 점수가 높은 덱은 색보다 **배치 규칙과 반복 부품**이 다르다.

| 차이 | Genspark 상위 덱 | nexa 지금 |
|---|---|---|
| 결론 자리 | 본문 오른쪽 어두운 결론 패널(46개 스킬, 104장) 또는 하단 결론 띠가 덱 내내 같은 자리 | 결론은 제목·`action` 띠 정도 |
| 표지 | 전면 사진·색 블록 + 숫자 격자·표제란(도면) 등 계열마다 다름 | 한 가지 배치 |
| 머리·바닥 | 러닝 헤더(덱 이름·장 번호·날짜), 메타 줄, 단계 진행 띠, 출처 띠 | 머리 칩 + 쪽 번호 |
| 강조 방식 | 명조 기울임 강조어 1색, 마지막 카드만 검정 반전, 거대 흐린 번호 | `==강조==` 색 글자 |
| 사진 | 전면·반쪽·세로 기둥·도판 줄 등 비율 변주 + 어둡게 깔기 | `photo_text` 한 가지 |

## 3. nexa 템플릿 후보 (선별)

점수 5점 26개와 4점 상위를 계열로 묶어, **지금 템플릿과 겹치지 않고 다시 쓸 데가 많은 것**만 골랐다.
"구조 부품"은 템플릿이 함께 가져야 할 고정 자리·반복 요소다(새 레이아웃은 [03](03-slide-archetypes.md)).

겹침 정리:
- 지금 `story`(미색·테라코타·명조 제목)는 `editorial`·`archive` 와 색이 비슷하다 — 새 템플릿은 **구조 부품**(결론 패널·도판 줄·러닝 헤더)으로 구분하고, `story` 는 `archive` 로 흡수하는 것을 검토한다.
- 지금 `report`(네이비)는 `ledger` 의 색만 있는 셈이다 — `ledger` 를 만들면 `report` 는 그 하위(결론 패널 없는 간단형)로 둔다.
- `채도 높은 SaaS` 는 흔하고 점수가 낮아(평균 2.9) 후보에서 뺐다.

## 4. 템플릿으로 옮길 때 지킬 것

- **1280×720 축소**: Genspark 는 1920×1080 이다. 좌표·글자는 ×2/3 로 옮기고, 그래도 15px 미만이 되는 라벨(고정폭 메타 줄 등)은 항목 수를 줄인다(nexa 검사 최소 크기).
- **강조 1색 원칙**: 상위 덱은 거의 모두 강조색이 1개(+ 상태색)다. 템플릿 토큰도 `primary` 외 강조를 늘리지 않는다.
- **같은 자리 반복**: 결론 패널·러닝 헤더·띠는 덱 내내 같은 좌표에 둔다 — 템플릿의 레이아웃 빌더가 고정 좌표로 그린다.
- **사진은 자리와 함께**: 사진 중심 템플릿(`keynote`·`archive`)은 자리마다 비율·어둡게 깔기·글자 안전 영역을 정해 둔다([04](04-image-slots.md)).
