# Genspark 슬라이드 스킬 전수 조사 (2026-10-02~)

> 목적: nexa-slide 템플릿이 "같은 틀에 색만 다른" 형태에 머물러 있다. Genspark 공개 슬라이드 스킬 156개(2,388장)를 전수 조사해
> ① 템플릿(색·배치·구조)으로 만들 대상을 고르고 ② 낱장 구성 중 고유한 것을 뽑아 레이아웃을 다양화하고
> ③ 목적별로 낱장을 엮은 샘플 덱을 만든다.

## 원칙

- **원본은 저장소 밖에 둔다.** 내려받은 HTML·이미지·SKILL.md 는 `D:\Projects\kiros33\_research\genspark-slides\`(로컬)에만 있다.
  이 폴더에는 우리 말로 정리한 분석과, 원본을 다시 만들 수 없는 요약 수치만 둔다.
- **디자인 값은 그대로 옮기지 않는다.** 색은 역할·색상 계열·명도(예: "따뜻한 미색 바탕 + 남색 글자 + 진홍 강조 1색"),
  글꼴은 계열(세리프 디스플레이·산세리프·고정폭)로 적는다. 템플릿을 만들 때 색·글꼴은 nexa-slide 가 새로 정한다.
- **구조는 기능 단위로 적는다.** "무엇을 보여 주려고 어떤 자리를 어떻게 나눴나"를 적고, 문구는 옮기지 않는다.
- 크기·좌표는 Genspark 1920×1080 값을 nexa-slide 1280×720 기준(×2/3)으로 바꿔 적는다.
